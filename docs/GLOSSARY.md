# 术语与代号表（先看这个，再看其他文档）

> 项目里代号很多，这份表只回答“这个词指什么”。写文档/汇报时**首次出现代号必须带中文解释**。

## 1. 检索相关的“编号”

| 代号 | 指什么 | 区分要点 |
|---|---|---|
| **W1** | 网页检索冒烟测试（10 条手写查询 × 360 图片） | 是**测试名**，不是版本 |
| **门卫 v2 / v3 / v4** | CLIP 门卫的**标签集版本** | v2=7 条反例；v3=+4 条（内饰/拼图/截图/广告）；v4=+1 条 keep（背景多车但主体清晰） |
| **批次 `web-smoke-XXXX`** | 每次跑批的**输出目录名** | `web-smoke-20261109` 基础批、`-hd-` 高清批、`-v3-` 4 查询小批、`-v5-` 升图后复跑 |
| **98 张** | 基础批 + HD 批下载成功的全部文件 | 按字节 sha1 去重后是 **52 张唯一图** |
| **升图** | 把 CDN URL 的缩放后缀（`!600`→`!1200`、`w_640`→`w_1280`）换成大图再下 | 不是超分，是 CDN 侧有更大母图 |
| **来源页回访（harvest）** | 图片搜索每条结果带 `link`；回访该文章页抽整页图 | 实验结论：产出不稳定，默认关闭，`--harvest N` 开启 |

## 2. 产品分层（L 系列）

| 代号 | 含义 |
|---|---|
| **L1.5** | 关联清单：用户输入 → 推荐车型/部件清单（页槽模型、惰性放闸） |
| **页槽** | 报告的一个版面位置；一个页槽 = 1 张合格主图 + 1 张备用，满足即停 |
| **惰性放闸** | 不追求“全清单查完”，按页槽需求逐层放开检索 |
| **任务单（brief）** | L1.5 的输出：工况/构型/部件配额/验收标准，交给检索执行 |
| **L2 / 检索中** | 按任务单执行检索的状态机 |
| **L3** | 确定性闸门（文本侧：对象/主题/具体性；图片侧：门卫/分层） |
| **L4** | 执行控制：重试、降级链、断点续跑 |

## 3. 检索状态机（`retrieval_engine`）

| 状态 | 做什么 |
|---|---|
| `BRIEF_READY` | 校验任务单/预算 |
| `LIBRARY_SEARCH` | 先查库内已有素材 |
| `FETCH` | 抓取/下载/去重/门卫 |
| `VERIFY` | 三证核验（身份/可见性/原厂），不通过不占槽 |
| `FILL` | 占槽 / 备选 / 族去重 |
| `GAP_CHECK` | 算全局覆盖：够→DONE；缺口→`EXTERNAL_DISCOVER`；本层耗尽→`DEGRADE` |
| `EXTERNAL_DISCOVER` | **缺口出现时才去找**车型/来源/查询目标 |
| `DEGRADE` | 开下一层（精确类目 → 环境特化 → 基型参照） |
| `WRITEBACK` | 回写证据 |

## 4. 图片可用性口径

| 词 | 判定 | 用途 |
|---|---|---|
| **概览可用** | 门卫通过 + 长边 ≥800 + 非多车 + 非强内饰 | 报告配图 |
| **部件可用** | 同上但长边 ≥1200 | 裁部件（踏步/格栅/轮拱…） |
| **参考层** | 门卫通过但长边 <800，或场景含其他车 | 可看、可当线索，不占可用名额 |
| **金标** | `data-test/evals/image-gate-52-20261109.json` | 52 张人工标注，改门卫/换模型前先跑 |
