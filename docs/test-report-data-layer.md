## 3. 结论

1. **三条不变量在存储层强制生效**：可推导状态不存储（完备度/槽位/待归号池全部为查询）、confirm_log 只增不改（数据库触发器保证，绕过应用层也改不了）、原图不可变（访问层拒绝覆盖）；
2. **派生查询与人工预期一致**：完备度分级、槽位状态、待归号池、三轴查询的行为与规范 §6 定义吻合——"凡可推导不存储"的设计律被验证可落地；
3. **往返一致成立**：导出包可完整重建数据库，为后续跨机迁移、备份、评测集分发提供了基础。

数据层可以作为 P1 素材资产库模块的地基。
