## 2. 左栏边界（你提的第二点）

低保真的左栏只有 logo + `EquipLens` + `最近`，高保真第一版把它画成了和页面同色的透明列，边界糊掉。现在：

- 左栏是**独立表面**：白→米白渐变 + 右缘 1px 细分隔 + 右侧投影（`box-shadow:16px 0 36px -30px`）；
- 内容区仍是浅灰底，两者一眼可分；
- 宽度回到 `clamp(200px,21vw,280px)`（v3 §1.1），从 y=0 起。

## 3. 关联程度与色彩（你提的第三点）

- 四级明示色（v3 §3 要求「高保真必须改为用户一眼能懂的明示色」）：
  - 精确类目 `#1F4B4F`（深青）
  - 环境特化 `#4E7E7A`（青）
  - 基型平台 `#8A9A94`（灰绿）
  - 跨车型 `#B3B9B6`（浅灰 + 虚线）
- 用在三处：S1 卡片色点与文字色、S1 清单横条底色+左色条、S2 图上框（虚线/实线都取该车层级色）。
- S2 的层级来自 S1 名录（按车型名匹配），不是另编一套。

## 4. 需要你确认的一处

「框的色彩跟随关联程度」这一点，v3 §4.4 只写了**状态**（虚线/实线/手柄），没写**色相**该不该跟层级走。我按你的话理解成「跟」，所以现在：同一台车的所有框 = 这台车的层级色，选中只改线型与手柄 4 个。若你本意是「框只跟状态、不跟层级」，我改回中性墨色即可（一行 CSS）。

## 6. 第二轮修正（2026-11-05 晚）

上一轮仍与低保真不符，逐条改：

| # | 问题 | 低保真事实 | 改法 |
|---|---|---|---|
| 1 | 底部把按钮和输入框合成一张白卡 | `.dock` 是 `background:linear-gradient(to top, 底色 62%, 透明)` 的**透明容器**，里面三个独立控件：`‹ 上一步`（独立按钮）、主行动（独立按钮）、`inputwrap`（自己带边框/底色的输入框） | dock 改为透明 + 底部渐变遮罩；三个控件各自成胶囊（白底 ghost / 墨色实心 / 白色输入框）。收起态主行动居中（实测偏差 0.0px），展开态：上行左=上一步、右=主行动，中间预判行，下行满宽输入框 |
| 2 | 清单「全是白的」 | 行是 `名称 + 构型·品牌 + 右侧层级标签`，第二行原因；`background` 按层级 13% / 7.5% / 4%，`border-left:2px` 层级色 | 去掉序号；改为「名称 + `6×6 · 陕汽` + 右侧 `精确/环境/平台/跨类·备选`」+ 第二行原因；底色 13%/11%/13% + 3px 色条；跨类虚线。像素校验：清单区 224 vs 白卡 235，肉眼可分 |
| 3 | 选中的彩色描边丑 | 低保真只用左上/右上勾选框区分选中，没有整卡描边 | 去掉彩色 ring；选中 = 卡片抬起 + 墨色实心勾 + 名称加重；未选 = 图片略淡。无彩色描边 |
| 4 | 右上角、左下角多了东西 | 卡片只有：勾选框（右上）、`1 / 3` 计数（右下），没有别的 | 第一版加的「右上角状态胶囊」与「左下角勾选徽标」已删除（DOM 计数 `.pill=0`、`.pick=0`） |
| 5 | S0 下面三张卡片 | 低保真 S0 只有 h1、副标题、输入框+开始、上传；没有「最近项目」卡片 | 已删（DOM 计数 `.rc=0`）；按钮只有 `开始` 与 `＋上传图片（可选）` |
