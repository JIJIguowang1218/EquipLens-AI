# 配色分析（参考图 → 设计令牌）

参考图是一张旅行规划类 AI 产品界面（Santorini 行程）。下面用**取样 + 聚类**读出它的用色，再映射到 EquipLens 的高保真实现。

## 1. 取样方法与结果

对截图按区域取色（k-means，k=6，每区按占比排序）：

| 区域 | 主色（占比） |
|---|---|
| 主视觉 hero | `#809EA5` 38% · `#9DB4B7` 26% · `#638389` 18% · `#D9E3E6` 2% |
| 内容卡片区 | `#E6E6E5` 31% · `#AAB3B3` 22% · `#CBCCC9` 21%（其余为照片色） |
| 强调卡（Assistant） | `#F5FB97` 24% · `#F3F7A9` 24% · `#ECEFBD` 27% |
| 窗口背景 | `#E0E0E0` 59% · `#D9D9D8` 15% |
| 顶部工具栏 | `#E1E1E1` 68% |

整图亮度很高，没有大面积深色块；饱和度集中在 hero 的青灰与那张柠檬黄绿的强调卡上。

## 2. 它把颜色用在哪（这就是我们要照搬的纪律）

| 颜色 | 参考图里的用途 | 为什么成立 |
|---|---|---|
| **浅灰底** `#E0E0E0` | 页面/窗口底，所有内容浮在它上面 | 底色不抢信息，卡片才显出来 |
| **白 / 近白** `#FFFFFF` `#E6E6E5` | 卡片、工具栏、输入条 | 靠"白 + 阴影 + 圆角"分层，不用描边 |
| **青灰** `#638389`→`#9DB4B7`→`#D9E3E6` | 只出现在**主视觉图**与图上叠的白色半透明 chip | 色彩来自照片本身，界面不额外加色 |
| **柠檬黄绿** `#F5FB97` | **只给一个东西**：那张"Assistant 正在给你建议"的强调卡，以及封面上的小面积装饰 | 全图最高注意力只给 1 处，所以它才像强调 |
| **近黑** `#1E1B14` | 正文、图标、主按钮（黑色圆钮） | 文字用黑不用彩色，保证可读 |
| **白 82% + 模糊** | 图上 chip（Overview / Hotels / Itinerary） | 图上信息靠"磨砂白"浮起，不用实色 |
| **灰阶文字** 3 级 | 标题 / 副标题 / 元信息 | 层级靠明度，不靠字号堆叠 |

一句话总结参考图的规则：**界面本身几乎无彩色；颜色要么来自照片，要么来自唯一一处强调；层级靠留白、圆角、阴影与明度。**

## 3. 映射到 EquipLens

| 令牌 | 值 | 用途（本实现） |
|---|---|---|
| `--bg` | `#EFEFEF` + 两处极淡径向光 | 页面底 |
| `--surface` | `#FFFFFF` | 卡片、查询条、动作坞、预览卡 |
| `--surface-soft` | `#F6F7F7` | 部件行、胶片、缩略图悬停底 |
| `--ink` | `#16191B` | 标题、当前阶段、主按钮底 |
| `--ink-2` | `#5C6467` | 正文（散文、form） |
| `--ink-3` | `#949B9E` | 元信息、未到的阶段名 |
| `--ink-4` | `#B9BEBF` | 占位、脚注 |
| `--teal-900/700/500/300/100` | `#2D4A4F → #DCE8E9` | 主图渐变兜底、图上框的"已框定"点、封面装饰；**不做大面积底色** |
| `--lime` / `--lime-deep` | `#E9F394` / `#DCEA6E` | **只给「进行中」语义**：状态灯脉冲、状态条进度线、部件行的「待框选」状态点。选中态与图上框改用关联层级色（见下） |
| `--t-exact/-env/-plat/-cross` | `#1F4B4F` / `#4E7E7A` / `#8A9A94` / `#B3B9B6` | 四级关联程度：卡片色点与文字、清单横条底色+左色条、图上框的虚线/实线颜色 |
| 阴影 | `0 10px 28px -14px rgba(20,28,30,.16)` | 卡片浮起；没有 1px 分隔线 |
| 圆角 | 卡 20–26 / 内块 14 / 胶囊 999 | 参考图的大圆角 |

## 4. 用色纪律（写进代码评审）

1. **不用线分区**：区域边界靠留白与卡片阴影，`border` 只用于极少数 1px 内分隔（如页脚上方）。
2. **lime 只表示「进行中」**：不参与选中态、不参与层级，面积应远小于 2%（实测 0.1%–1.4%）。
3. **青灰只跟图走**：没有图的地方不要铺 teal 底。
4. **文字三级灰**，不引入彩色文字（关联轴除外，它用色点而非彩色字）。
5. 图上信息一律"磨砂白 chip"（白 82% + `backdrop-filter: blur(10px)`）。

## 5. 与低保真的关系

低保真是深色（墨底纸色）、靠 1px 线分区；高保真按参考图改成浅色、卡片化。**低保真只提供尺寸与区域关系（8/4 分栏、每行 3 辆、dock 位置），不提供配色与描边**。两套并存：`docs/ui-mock/v4/` 是结构稿，`docs/ui-hifi/` 是视觉稿。
