# 高保真可交互页面（v1 · 浅色）

> 暗色重设计版（Darkroom v2）见 [../ui-hifi-dark/](../ui-hifi-dark/)。本目录保留浅色版做对照，内容未改。

打开 `index.html`，或直接开 `s0.html`。四页串起来是一整条流程：立项 → 检索 → 素材与分析 → 排版。

## 状态与等待

每页支持 `?s=loading|ready`：

| 页 | loading 表现 | 时长 |
|---|---|---|
| S1 检索 | 骨架卡 + "检索中"脉冲 + 进度条推进，结果**逐张**入场（`已找到 n / 6`），右栏清单同步长出来 | 0.9s 后开始，逐张 340ms，约 3.6s 完成 |
| S2 分析 | 照片模糊 + 部件行骨架 + "分析中" | 2.6s 后整体揭示，框随行入场 |
| S3 排版 | 画布骨架 + 预览页**逐页**生成 | 0.6s 后开始，逐页 160ms，约 2.6s |

不带参数时 S0 直接 ready；S1/S2/S3 默认走 loading，方便从上一页点进来看过程。
点主按钮会带 `?s=loading` 跳到下一页。

## 数据

`data.js` 由 `python scripts/build_hifi_data.py` 从 `data-test/ui-fixtures/*.json` 生成（内联，避免 `file://` 下 fetch 被拦）。
图片指向 `../../data-test/ab-images/`（真实实拍 70 张）。内容为**模拟数据**，只用于看效果。

## 已验证

- 1440×900 无横向溢出、无控制台报错、无文字裁切；
- 进度条文字在所属线段正中（实测偏差 0.0px）；
- 内容区 8/4 分栏（736 / 360，含 16 gutter），dock 与内容同宽（1112）；
- dock 主行动与 dock 中心偏差 **0.0px**；输入框右缘 1404（dock 右 1416）；
- 展开态：上行 = 上一步 / 预判 / 主行动，下行 = 满宽输入框（dock 60→106px，内容区同步收缩）；
- S1 八张卡三行放得下（705 = 705，不滚动）；备选卡虚线、勾选框在右上；
- 清单横条四级底色与左色条生效；S2 框默认虚线、选中实线 + 4 手柄；
- 等待态主按钮禁用，完成后启用。

与约定的逐条对照见 [CONFORMANCE.md](CONFORMANCE.md)。
