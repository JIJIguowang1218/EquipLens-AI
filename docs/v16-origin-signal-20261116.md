## 0. 结论

1. **No-Go：拿不到“候选级、可审计”的国别信号。** 三种候选最多给到“品牌级”，且口径不唯一；
   要落到交付候选就必须做品牌→国别映射，这正是 `vocabulary-policy` §1 禁止进 `src` 的领域实体表。
2. **硬占比是结构上不可行，不只是“缺来源”。** 硬配额要求每个槽位可判定；证据覆盖 <100% 时，
   未知项只能“阻塞交付”（与 P0 交满 N 冲突）或“默认算国产”（不可审计），二者都不可接受。
3. **维持现状**：`foreign_ratio`/`brand_quota` 软约束 + 交付披露；`origin` 仅在用户显式说
   “只要进口”时按 `source=user` 记硬约束。V16 不排产、不接生产。

## 1. “可审计”必须是什么意思

结合 `vocabulary-policy` §1/§1.4，本任务里“可审计”= 同时满足 5 条：

| # | 要求 | 判定 / 记录方式 |
|---|---|---|
| A1 | **来源可定位** | URL / Wikidata QID / 公告批次，能重新打开；不是模型记忆或直觉 |
| A2 | **可复现** | 抓取时间 + 内容 sha256 / 修订号；同一证据→同一标签；规则确定，无隐藏 LLM 先验（E50 教训：无标注集不得加权） |
| A3 | **口径唯一** | 先声明是“品牌母国 / 母公司国籍 / 生产地 / 设计地”哪一个；冲突要记录，不许强行二值化 |
| A4 | **可失败** | 写清失败是“放行/丢弃/降权”（policy §1.4）；允许 `unknown`，但不许静默默认 |
| A5 | **不入主链枚举** | 证据/缓存放仓库外或 `data/`，显式参数传入；默认路径不得指向它；过 `tests/test_no_legacy_tables.py` |

**关键：国别至少有 4 种互不相同的语义。** 卡特彼勒（徐州）生产 → 生产地中国、品牌母国美国；
山东临工被 Volvo CE 控股 → 品牌母国中国、母公司国籍瑞典；福田戴姆勒是 50:50 JV → 归属本身有争议。
没有单一公开源同时给出这 4 个口径，而“占比”的分母是**交付候选**，需要候选级标签，不是品牌百科条目。

## 2. 三个候选信号

| 信号 | 可得性 | 覆盖率 | 成本 | 法律 / ToS | 主要失败模式 | 无表可自动化？ |
|---|---|---|---|---|---|---|
| **(a) 用户显式品牌清单** | 仅当用户点名；V8 品牌解析 5/5 | 只覆盖被点名品牌；“外国品牌占 1/3”不点名 → 0 | ≈0；代价是多问一次（与 S0 只对破坏性操作澄清冲突） | 无 | 清单不全；用户说的“进口”可能指产地非品牌；未点名候选无标签 | **部分**：用户直接给标签可记 `source=user`；算全池占比仍需标其余候选 → 否 |
| **(b) OEM 官网/官方注册信息** | 大品牌有 global/about 页；长尾/专用车改装厂无英文站，或 JS/反爬 | 按品牌提及较高（大品牌主导），长尾弱；到不了型号级 | 1–3 次抓取/品牌 + 抽取；缓存后≈0；人工抽检 1–2 h | 公开页，但逐站 robots/ToS/版权不同；只存 URL+短引文 hash，不存正文 | 页面只写“global”不写国别；并购/JV 改变归属；改版/本地化跳转；无型号级 | **单品牌可**（抓→抽→引用）；但“标题品牌词→官网域名”是模糊映射，缓存即事实表 |
| **(c1) MIIT 公告**（工信部） | 高：官方免费，173 批起可查企业/产品并下载参数页 | 中国公告内车型强；不在华销售的外国车型缺 | 免费；PDF/Excel 解析 + 企业→品牌对齐 1–2 天 | 政府公开信息，可用；批量抓取守频率/robots | 字段只有企业名称/注册地址/生产地址/商标，**没有品牌国别**；JV/代工使生产地≠品牌母国 | **否**：必须建“企业/商标→品牌→国别”对照 |
| **(c2) 海关 HS 编码** | 公开月度统计（HS×原产国），非品牌级；官网本次自动抓取返回 HTTP 412 | 贸易流量，无法 join 到候选 | 聚合免费；品牌级报关明细需商业库（付费/授权） | 公开统计可用；商业数据需授权；不得绕过反爬 | 无品牌/型号键；转口/贸易商扭曲原产国 | **否**：没有 join key |
| **(c3) Wikidata P495** | 公开 SPARQL、CC0；大品牌有 P495，中国 OEM/长尾稀疏 | 品牌级中等；引用常缺失 | 免费；有查询限流；实体解析+人工复核 | 数据 CC0；query service 有使用政策，2026–27 后端迁移会改 endpoint | 品牌 vs 产品实体混淆；P495 语义混杂（母国/生产地）；可被编辑 | **否**：标题→QID 需实体解析，缓存结果即表 |

补充：`origin` 目前无生产实现，`Verification.origin` 恒 `unknown`（K2）；E50/A1 已否决“来源权威加权”
（误伤 10.7%–54%），本文件的国别信号不得换个名字复活该机制。

## 3. 最小实验：建议“不跑正式 V16”，只留一个有界探针

**建议不跑**面向生产的 V16。理由：实验能回答的“标签是否存在”已被 §2 否掉；
实验不能回答的“硬占比能否交付”，已被 E15/K11 的供给上限（加进口查询 16–20% vs 18–24%）挡住——
即使标签完美，硬配额也只会把供给缺口变成交付失败。

若台账仍要重开，只允许下面这个 **V16-min 证据探针**（不是生产实验）：

- **输入**：冻结的三轮候选池去重后的品牌集合，取高频前 30 个（覆盖 ≥80% 候选提及）。
- **样本**：30 品牌 ×（1 个官方 about/registry 页 + 1 条 Wikidata P495）；双人独立打标，隔日重标一次。
- **记录**：URL/QID、抓取时间、sha256、口径（母国/母公司/生产地）、`unknown`、冲突原因。
- **指标**：口径一致率、可引用覆盖率、JV/并购冲突率、单品牌耗时。
- **停止规则**：一致率 <90% 或 冲突率 >10% 或 覆盖率 <70% → 立即停，维持软约束；
  **即使全过也只允许“交付展示列”，不得做硬配额**（供给与覆盖两条仍不满足）。
- **成本**：≤0.5 人日 + ≤¥5 抽取费；产物放 `data-test/evals/v16-*`，不进 `src`。
- **禁止**：不建品牌→国别表进 `src`；不改 `brief`/`planning`/`engine`；不新增实验编号。

## 4. Go / No-Go

| 决策 | 结论 | 依据 |
|---|---|---|
| 自动国别信号进生产链路 | **No-Go** | §2 无候选级源；A5 与 `vocabulary-policy` 冲突 |
| 硬性外国品牌占比 | **No-Go** | 覆盖 <100% 时未知项无合法处理；E15 供给上限 |
| `source=user` 品牌清单（软输入） | **Go（有限）** | 用户输入不是词表；已有 `brands_include` 解析链路 |
| 交付展示“国别（来源/时间）”列 | **可选，后续单列** | 只能展示、不得参与配额/准入/排序 |

**重开条件**（满足任一才重评，并按 `killed-strategies.md` §4 预注册）：
① 出现候选级、带引用、覆盖率 ≥99% 的国别源；② 产品接受“未知即披露、配额永不硬”的新口径。

**台账影响（待产品拍板，本文件不直接改）**：S0-01/§8#4 的“V16 未跑”可改为
“V16 已评估：No-Go（2026-11-16，`docs/v16-origin-signal-20261116.md`）”；软约束结论不变。
