# 旁白录制说明（交给配音 / 自己录）

## 一、交付格式（首选）

- **一条完整音频**：`WAV`，**48 kHz / 24 bit / 单声道**
- 如果只能录 44.1 kHz / 16 bit，也可以
- 从第 1 句读到第 19 句，一次读完，**句与句之间停 0.8–1.0 秒**
- **开头留 0.5 秒静音，结尾留 1 秒**
- 文件名：`equiplens-vo-<你的名字或日期>.wav`

## 二、次选：一句一个文件（更好对轴）

- `01.wav` … `19.wav`，共 19 个文件，编号与朗读稿一致
- 每句开头留 0.2 秒静音，句尾自然收
- 放在一个文件夹里，压缩成 zip 发我

## 三、录音环境

| 项 | 要求 |
|---|---|
| 房间 | 小房间、有软装（衣柜/窗帘/沙发）。**不要**浴室、空房间、会议室（回声重） |
| 麦克风 | 离嘴 **一拳到两拳（10–20cm）**，**稍微偏 15°**，别正对（防喷麦） |
| 设备 | 手机自带录音也行，但**别用免提外放** |
| 环境 | 关空调/风扇/窗；手机开飞行模式，别放桌面上（震动） |
| 处理 | **不要**降噪、不要混响、不要压缩、不要加音乐、不要淡入淡出 |

## 四、读法

- **语速**：约 **4.2 字/秒**（自然偏慢，像给人讲清楚一件事，不是念稿）
- **停顿**：句号处停 0.8–1.0 秒；分号/冒号处停 0.3–0.4 秒
- **语气**：前半段（1–5 句）平实陈述；中段（6–15 句）笃定、有判断；结尾（16–19 句）放松、收住
- **不要**：播音腔、上扬的综艺感、每句都重音、抢拍
- 读错一句：**停 2 秒，从这一句开头重读**，我按静音切分，不用你剪

## 五、我会做的处理（你不用管）

1. 自动切句 + 静音检测 → 对齐到时间轴
2. 统一响度到 **-16 LUFS**，峰值 -1.5 dB
3. 轻降噪 + 去齿音（只做必要程度）
4. 与配乐混音（人声在前，音乐压到 -22 dB 左右）
5. 画面不重渲，只换音轨

## 六、最容易被退回的四个原因

| 问题 | 后果 |
|---|---|
| 房间回声重 | 后期压不掉，只能重录 |
| 麦克风正对嘴 | 爆破音（"碰""八"）刺耳 |
| 语速忽快忽慢 | 对不上画面节奏 |
| 一句里中途换气/改词 | 切句会断，需要重录该句 |

## 七、提交

- 音频（或 19 个文件）＋ 一句备注："按第 X 版稿子读的，第 N 句改成了……"
- 如果改词，把改后的句子发我，我重排时间轴再对音
