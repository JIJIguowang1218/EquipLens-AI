## 1. 用户旅程更新（as-is v2）

依据 2026-10 需求讨论补充的真实工作流整理。**关键结论：现状并非纯人工流程，而是"人工 + 通用网页 AI"的半自动流程**——设计师已经在用网页 AI 做名录检索和部件分析，痛点在环节之间无法衔接（匹配、裁图、排版仍全人工），且把企业素材发给通用 AI 存在合规隐患。

### 1.1 素材现状（输入侧）

- 来源：甲方提供的竞品图片（多为现场拍摄）+ 设计师本人历史拍摄的图片；
- 特征：**实拍为主、背景杂乱、角度多样、多型号混杂且无标注**；
- 现状处理：人工分类 + 借助工具**逐张辅助识别**车型并打标（依靠车辆外观特征肉眼判断，而非仅靠 Logo/铭牌）。

### 1.2 素材不足与补充原则

- 不足分两种情况：**① 单纯数量不够；② 同类型产品数量不够**（如特种车辆竞品少，可参考类似工程车辆）；
- 补充原则：**涵盖业内最重要的品牌**；
- 现状补充流程（半自动）：

```
向网页 AI 发送车辆类型需求
→ AI 返回产品名录 + 网页链接
→ 人工逐个点击链接，获取型号与图片信息
```

### 1.3 完整制作流程（13 步）与模块映射

| # | 环节 | 现状方式 | 对应 PRD 模块 | 差距/备注 |
|---|---|---|---|---|
| 1 | 竞品素材导入 | 甲方提供 + 历史拍摄，零散混杂 | FR-1.1 输入 | — |
| 2 | 逐张识别并标记车型号 | 人工分类 + 工具辅助肉眼识别（靠外观特征） | FR-1.1 | **识别依据是车辆特征而非仅 Logo**，比 PRD 假设更难；见 G2 |
| 3 | 判断素材是否足够 | 人工判断（数量 / 同类型两类不足） | FR-4 前置 | 新增"素材充分性评估"能力；见 G3 |
| 4 | 联网补充竞品 | 网页 AI 给名录+链接 → **人工逐链接取图** | FR-1.2 | PRD 排 P1.5；现状已是流程标配环节，见 G4 |
| 5 | 原有图片匹配型号信息 | 人工（已知型号清单 → 逐图对号） | FR-1.1 | **闭集匹配**子任务，PRD 未明确；见 G2 |
| 6 | 新图 + 原图发给 AI 分析指定部位 | 通用网页 AI 对话 | FR-2.3 | 现状可用但无结构化输出、无溯源 |
| 7 | 获取型号与指定部件分析文字 | AI 返回 + 人工整理 | FR-2 | — |
| 8 | 人工截取部件截图，与分析文字匹配排版 | **全人工** | FR-2.3（裁图）+ FR-5（排版） | 自动化收益明确的环节 |
| 9 | 选主图（展示整体形象） | 人工挑选，一般 3/4 前脸 | FR-2.1 | — |
| 10 | 绘制特征线凸显图 | **全人工**：主图复制 → 降透明度 → 手描特征线（整体走势 + 关键形象信息，数量不多，一般 3/4 前脸视角） | FR-3 专项 | 获得具体规格，见 G5 |
| 11 | 排版输出 | 人工（PPT 排版） | FR-5 | 核心自动化目标 |
| 12 | 情绪版制作 | 人工 | 品牌定位情绪版（PRD 排 P2） | **as-is 中是标准步骤**，见 G6 |
| 13 | 封面封底制作 → 输出整体报告 | 人工 | FR-5.3（仅封面，简版） | **封底在 PRD 中缺失**，见 G7 |

### 1.4 旅程更新识别的差距（G1–G7）

- **G1 素材充分性评估**：流程中存在"判断素材是否足够"的隐性环节（两种不足类型），PRD 未覆盖。建议纳入 FR-4（报告规划的前置输入）。
- **G2 识别任务重构**：真实流程是"先有型号名录，再把照片对号入座"的**闭集匹配**，而非纯开放集识别；且识别依据主要是车辆外观特征（驾驶室形状、底盘构型、涂装家族），Logo/铭牌只是辅助。FR-1.1 的验收口径需按此修订（闭集匹配准确率可显著高于开放集）。
- **G3 近似车型参考**：竞品集定义应扩展为"**同类设备 + 近似类目设备**"。行业惯用类比链（有官网产品树佐证）：非公路刚性矿卡 ↔ 矿用宽体自卸车 ↔ 重卡工程版（8×4 宽体自卸）。
- **G4 联网检索优先级**：现状流程中"网页 AI 给名录 → 人工点击取图"已是标准环节且全人工耗时，FR-1.2 的优先级论证比 PRD 当前表述更充分。可考虑 MVP 内先做**轻量形态**（生成型号名录 + 来源链接清单，人工点击），全自动抓取仍留 P1.5。
- **G5 特征线规格具体化**：输入 = 3/4 前脸主图；做法 = 降透明度底图 + 少量手描矢量线（整体走势 + 关键形象线）；产出 = 叠加图。FR-3 实验的达标标准可据此具体化（线条数量级、描线位置与设计师手描结果的重合度）。
- **G6 情绪版时点**：as-is 中情绪版是每份报告的标准步骤，但 PRD 将其排至 P2。需重新权衡（详见 §3 与待确认问题 #6）。
- **G7 封底缺失**：附录 A 页型表无封底，FR-5.3 应补"封面 + 封底"。

## 2. 外部调研：专业设计调研报告的结构与写法

> 调研执行于 2026-10-03，三个方向并行检索（设计竞品分析报告结构 / 情绪版与定位图方法 / 色彩趋势报告惯例）。以下每条标注【来源】（有可溯源页面）或【推断】（综合行业惯例）。参考 URL 全清单见 §7。

### 2.1 专业报告的典型页序（对标现有样例）

完整的"设计前期竞品分析" deck 行业典型页序【推断，有方法论来源佐证】：

```
封面 → 方法论说明页 → 市场格局概览 → 造型/CMF 趋势页
→ 竞品单车分析页（一车一页）→ 横向对比矩阵页 → 风格定位图页
→ 局部设计分析页 → 品牌设计基因页 → 品牌定位情绪版页 → 结论/机会点页（+ 封底）
```

对照样例报告《早期卡车分析》（PRD 附录 A）：**已有** 封面 / 单车页 / 局部页 / 品牌页 / 情绪版；**缺少** 方法论页、市场格局页、横向对比矩阵页、风格定位图页、机会点结论页、封底。这与 §3 的增强提案一一对应。

### 2.2 分析文字的写法（直接可用于 Prompt 设计）

- **四段式骨架**【来源：Form Trends 车型设计故事归纳】：形态/图形变化（改了什么）→ 材质工艺（CMF）→ 姿态/比例效果（stance/proportion）→ 设计意图或用户价值（为什么）；
- **篇幅惯例**【推断】：部件描述 1–2 句，整车描述 3–4 句；
- **语体**：客观形态事实 + 评价性形容词的混合体，行业文字允许强烈判断（如 aggressive / bland / 犀利、精干、整体感）【来源】；
- **术语栈**（中英对照，建议沉淀为附录 B 的扩展词表）：姿态 stance、比例 proportion、特征线 character line、DLO（daylight opening）、灯组签名 light signature、格栅图形 grille pattern、轮眉 wheelarch、倒角 chamfer、体量 monolithic / 分层 articulated、CMF（色彩/材质/表面工艺：肌理、闪粒 sparkle、flop 翻转效应、哑光、触感效果）【来源】。

### 2.3 情绪版（Moodboard）专业惯例

- 构成三件套：**情绪关键词 + 意象图片网格 + 简短注解**（注解说明"为什么放这张图"）【来源：IxDF】；
- 关键词必须简短且能回指到具体意象；单版意象图常见 12–30 张、统一裁切、松散网格 + 留白【推断】；
- 行业禁忌：**事后补拼情绪板**（项目做完再凑图）一眼可辨；情绪板在流程上应位于竞品对标之前、作为后续草图的回溯依据【来源：Form Trends】；
- 定位：专业情绪版是"研究证据"而非装饰图【来源：Craft Research 2011 论文】。

### 2.4 风格定位图的方法论

- 方法源头：Kansei 工学 + 语义差异法（SD 量表）——把感性词汇量化后与设计要素建立映射【来源：Nagamachi 1995；Jindo & Hirasago 1997；SAE 2000-01-3412 商用车应用】；
- 公开案例：14 车型 × 37 对 SD 形容词 → 因子分析提取两个正交语义维度（potency 强势感 / dynamism 动感）→ 二维散点定位【来源：Semiotics 2015】；
- 轴对惯例【推断，有文献支撑】：硬朗↔圆润、力量感↔轻盈、传统↔前卫、豪华↔实用；两轴应选正交语义；
- 图表形态：二维散点 + 品牌车型缩略图/Logo 叠加【推断】。

### 2.5 色彩策略页的行业范式

- 双层结构【来源：Axalta / BASF 年度报告】：
  - **数据层**：色彩占比统计（如 Axalta：全球白 38%、黑 19%、灰 13%、银 10%，前四色约 80%），按区域/车型段细分，标注同比变化；
  - **观点层**：数据之后由色彩设计师做文化解读与趋势阐释；
- BASF/PPG 观点型报告惯例：年度主题 → 分区域关键色（概念化命名）→ CMF 工艺趋势（闪粒、flop、哑光、功能性颜料）；
- 色彩策略页应与风格定位衔接：先有风格定位，再按风格族派生色板【来源：Applied Sciences 2023】。

### 2.6 方法论页的专业写法

- 来源分层声明：一手研究（专家评分/量表）/ 二手统计（行业报告、销量数据）/ 桌面研究（官方图片、媒体报道），各注明年份与覆盖范围【来源：NN/g】;
- 可信度四原则：systematic（固定流程）、transparent（写明竞品清单与评分者背景）、reproducible（量表与轴对定义可复用）、synthesized（数据→洞察推导链可见）【来源：positioning 综述 2020】;
- 局限性声明是行业惯例：样本范围、定性判断、数据年份等限制需明示【来源：NN/g】。

## 3. 报告页面增强提案（任务 1 评估）

**总体评估结论：值得增加，且外部调研显示缺的正是"综合决策类"页面。** 但增页有三项隐性成本——每种新页型 = 新模板 + 新评测集 + 可能的新检查点——因此建议按"数据依赖"分三期，而不是一次性全加。另一个原则：**报告结构可以一步规划完整（附录 A 扩展），但自动生成能力分期上线**；未到期的页型支持人工/半自动填充。

### 3.1 提案清单

| 编号 | 页型 | 内容 | 数据依赖 | AI 可行性 | 建议 | 
|---|---|---|---|---|---|
| A | 竞品总览页 | 全部竞品缩略图矩阵：主图 + 品牌/型号 + 风格关键词 + 主色条，一页总览 | 仅单车分析数据（FR-2） | 高（纯聚合渲染） | **P0**，MVP 可含 |
| B | 方法与来源说明页 | 素材来源与数量、分析方法、局限性声明 | 流程数据自动汇总 | 高 | **P0**，成本极低、显著提升可信度（尤其面向国企评审） |
| C | 封底 | 品牌/团队落款、免责声明 | 模板 | 高 | **P0**，补 FR-5.3 缺口 |
| D | 横向对比矩阵页 | 行 = 造型属性/参数（姿态、体量、灯组形式…），列 = 竞品；参数行与评分行分层 | FR-2 数据 + 新增属性评分输出 | 中高（评分需评测校准） | P1 |
| E | 风格定位坐标图页 | 二维语义定位图（散点 + 车型缩略图），轴对可选 | FR-2.4 需扩展为"关键词 + 语义坐标" | 中（VLM 打分 + 人工确认） | P1 |
| F | 市场格局概览页 | 该类别品牌梯队图 + 代表型号（默认数据已调研产出，见 §7.3） | 内置静态品牌格局数据 | 高 | P1 |
| G | 色彩策略页 | 跨竞品色彩占比聚合 + 行业色彩数据引用（Axalta 类）+ 按风格族分组的色板 | FR-2.2 聚合 + 外部数据 | 中 | P1/P2 |
| H | 造型/CMF 趋势页 | 趋势方向 + 意象案例，form 与 CMF 分列 | 联网检索（FR-1.2）+ 趋势资料，需溯源 | 中低（时效与合规复杂） | P2 |
| I | 法规与人机约束页 | 类别相关法规/视野/照明约束摘要 | RAG 知识库（M5） | 中 | P2 |
| J | 设计机会点页 | 横向观察与差异化启示 | 全部数据 | 高 | **待讨论**：与"报告不含第一轮设计方案"的边界有冲突风险，见 3.3 |

### 3.2 分期汇总

- **第一期（MVP 即可，零外部依赖）**：A 竞品总览、B 方法与来源说明、C 封底——全部由既有数据/模板聚合而成，不新增分析能力；
- **第二期（P1）**：D 对比矩阵、E 定位图、F 市场格局——需要小的数据结构扩展（属性评分、语义坐标）或内置数据资产；
- **第三期（P2，依赖检索/RAG）**：H 趋势页、I 法规页、G 色彩策略页完整版。

### 3.3 需要产品负责人拍板的三个点

1. **MVP 是否扩容**：若不想扩 MVP，第一期三页可定位为"紧随 MVP 的首批增页"而非 MVP 内置；
2. **机会点页的边界**：若加入，建议措辞约束为"横向观察与启示"（描述差异与空缺），不出现设计方向建议，以守住"报告不含第一轮设计方案"的产品边界；
3. **情绪版是否提前**：as-is 中情绪版是标准步骤，简版情绪版（关键词 + 意象网格 + 注解）技术难度不高，主要制约是**意象图来源与合规**（网络检索图库的授权边界），需与 FR-1.2 的合规问题一起定（待确认问题 #6）。

## 4. 用户调研建议（任务 2）

### 4.1 对"报告作为调研产出物"的专业性建议

1. **写法规范化**：采用 §2.2 四段式骨架与术语栈，将其沉淀为 Prompt 资产与附录 B 扩展词表（中文术语 + 英文对照 + 正反例）；
2. **每页可回溯**：单车页与对比页的结论应能回指方法论页声明的数据来源（呼应 NFR-6 可溯源）；
3. **情绪版按三件套生成**：关键词 + 配图 + 注解，注解由 AI 生成"为什么放这张图"，供设计师审阅修改；
4. **定位图先做"专家打分简版"**：AI 给初始语义坐标 → 设计师在检查点二人工微调 → 渲染。不需要一上来做多被试量表实验；
5. **色彩页区分数据层与观点层**：竞品实拍取色是数据层；行业占比引用外部报告并标注年份来源；
6. **新增方法论页**：自动汇总素材来源、数量、视图分布、处理方式与局限性——这是成本最低、对"专业性观感"提升最直接的一页。

### 4.2 对产品前期用户调研方法的建议

当前调研材料（旅程口述 + 样例报告）已覆盖主流程，建议再补三类动作：

1. **影子观察 1–2 次**：请设计师实际制作一份报告时记录各环节耗时（拆到 §1.3 的 13 步粒度），一次性校准开放问题 #1 的工时基线和"哪一步最痛"；
2. **报告评审会侧记**：跟随一次向国企客户的汇报，记录客户追问/质疑的点——这直接决定增强页型的取舍优先级（客户问"你怎么选的竞品"→ 市场格局页；问"趋势是什么"→ 趋势页）；
3. **历史报告语料收集**：收集 3–5 份不同项目的历史报告作为评测基准（evals 语料）与页面规划策略的训练参考；
4. **卡片分类**：用 §3.1 的页型清单做一次简单卡片分类（让设计师按"必须有/最好有/不需要"分组），低成本验证增页假设。
