EQUIPLENS-AI / 产品说明书01 / 产品定义
01 / Product Definition

设计前期的竞品分析报告

EquipLens-AI 服务的是工程车辆外观部件迭代项目的设计前期。它在第一轮造型方案开始之前，把竞品素材组织成一份可讨论、可修改的分析报告，用于和客户对齐设计风格与设计边界。

01 / START
项目立项设备类别、客户、目标市场
02 / THIS PRODUCT
设计前期分析竞品清单、素材、分析、报告
03 / NEXT
第一轮造型方案在共同判断之上开始设计
04 / REVIEW
方案评审客户对齐风格与边界
使用环节

外观部件迭代项目的设计前期，项目启动后、第一轮造型方案开始之前。

读者：设计团队、设计管理、企业客户评审人。

报告目的

对齐设计风格与设计边界；明确竞品在同类部件上的做法、共性与差异。

输入 / 输出

输入：类别、部件、竞品范围、页数预算、客户资料。

输出：竞品清单、单车页、可编辑 PPTX（主）/ PDF（辅）。

边界

做：竞品与部件级分析、清单与页序、可编辑版面、来源可追溯。
不做：第一轮造型方案、替代设计师判断、整页贴图、无证据结论。

EQUIPLENS-AI / 产品说明书02 / 用户与现状
02 / Users & Current Workflow

前期分析报告的现有生产流程

这份报告目前由工业设计师主责，设计管理与前期调研协同，最终用于客户汇报。生产流程高度依赖个人经验，工具之间没有形成数据链路。

01 / INTAKE

接需求

设备类别、竞品范围、关注部件；口径靠经验。

工具 / 项目会 · 客户输入
02 / COLLECT

找素材

甲方提供、展会拍摄、网络收集；图散、背景乱。

工具 / 搜索 · 图库 · 聊天
03 / SORT

整素材

筛选、去重、按车型/视角/部件归类；认型号。

工具 / 文件夹 · PS · 肉眼
04 / ANALYSE

读图分析

看造型、色彩、部件、CMF；写分析。

工具 / PPT · Word · 网页 AI
05 / LAYOUT

排版

一车一页、套母版；改字牵动整页。

工具 / PowerPoint · WPS
现状的四个卡点
素材不可复用

每次项目重新找图、重新归类。

分析口径不稳定

不同设计师对同一部件描述不一致。

版式返工

改一个字、换一张图，可能牵动整页。

结论留不下来

分析散落在历史 PPT，无法结构化复用。

现有替代方案
方案不足
人工 + 通用网页 AI能写文案，不理解部件、版式与证据。
图库 + 人工整理素材多，分析与报告仍靠人。
通用 AI PPT能排版，没有清单、证据链、分析 schema。
现状判断
工具很多，链路没有

报告仍然靠人拼接；每一段劳动都没有可复用的产物。

产品机会
把报告拆成四个对象

清单、素材、分析、页面；每段有产物、可确认、可回溯。

现状不是缺工具，是缺一条把工具串起来的链路。
