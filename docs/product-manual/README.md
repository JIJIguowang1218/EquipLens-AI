## 口径说明

- 文中指标分为 **目标（Target）**、**实测（Measured）**、**验收（Acceptance）** 三种口径，不混用。
- 实测数字来自 2026-10-31 的检索线离线评测、单批图片门卫记录与关联清单 A/B 样例；样本有限，随评测集扩充修订。
- 示例车型图片来自公开网络，仅用于版式与产品能力演示，不代表真实客户项目或最终结论。
- 用户画像中的姓名为化名；工时曲线为定性示意，待基线测量后校准。
