## 1. 产品概述

### 1.1 产品定位

EquipLens-AI 是面向工程机械（重卡、装载机、起重机、矿用车辆等）**外观部件设计前期分析**的 AI 辅助工具。它利用大模型的**多模态图像识别、检索与筛选、工具调用**能力，协助工业设计师在项目启动阶段快速产出**可编辑的前期分析报告（PPTX 为主，PDF 为辅）**，用于向合作企业客户（国企为主，如中国重汽、徐工、三一等）汇报交流前期看法，**确认设计风格与设计边界；报告不包含第一轮设计方案**。

### 1.2 背景与痛点

前期分析报告（竞品造型分析、品牌定位等）目前高度依赖人工：

1. **素材检索与整理成本极高**：竞品图片来源零散（甲方提供、展会拍摄、网络收集），无分类、背景杂乱、质量参差，人工检索、筛选、归类、标注耗时数天；
2. **分析专业门槛高**：色彩比例分析、特征线条提取、部件级造型描述需要专业训练，质量依赖个人经验；
3. **排版与格式化占用创意时间**：一车一页的版式重复劳动量大；
4. **知识难以沉淀**：竞品素材与分析结论散落在历史报告文件中，无法复用。

### 1.3 目标用户

| 用户 | 使用场景 | 核心诉求 |
|---|---|---|
| 工业设计师（主要用户） | 外观部件迭代项目的设计前期 | 快速得到可编辑、专业可信的分析报告初稿，把时间留给判断与创意 |
| 设计管理 / 前期调研人员 | 对客户汇报前的资料准备 | 竞品覆盖全面、结构规范、能快速调整 |
| 企业客户（阅读者，间接用户） | 汇报会上评审前期分析 | 观点清晰、图文专业、可讨论确认 |

### 1.4 产品目标与成功指标（暂定，待基线核实后修订）

| 维度 | 指标 |
|---|---|
| 效率 | 一份 10–15 个竞品的前期分析报告制作时间，由人工约 3–5 天压缩至 ≤ 1 天 |
| 可用率 | AI 生成单车分析页的"直接采用率" ≥ 60%（即人工修改量 ≤ 40%） |
| 质量 | 部件类别标注准确率 ≥ 85%；描述文本设计师评分 ≥ 4/5 |
| 成本 | 单份报告 AI 调用成本可测量、可复现；通过评测找到质量 / 成本甜点组合 |

## 2. 术语表

| 术语 | 定义 |
|---|---|
| 竞品分析单车页 | 报告中"一车一页"（重点车型可两页）的竞品分析版面，本产品 MVP 的核心产出物 |
| 色彩比例条 | 单车页顶部按占比横向展示车身主色（2–4 色）的色条 |
| 特征线条提取 | 在去饱和底图上以品牌色矢量线描出造型主特征线的可视化分析手法 |
| 部件标注 | 对指定部件的特写裁图 + `#部件类别` 标签 + 1–3 行专业描述（形态/材质/工艺/姿态） |
| 风格关键词 | 概括该车型造型风格的三词组（如 ·刚直·硬朗·沉稳），置于单车页右上角 |
| 品牌家族 | 同一汽车品牌下的车型分组，报告竞品分析章节按品牌家族顺序组织 |
| 局部设计分析 | 针对指定部件（如登车踏步、翼子板）跨设备集中对比的章节 |
| 情绪版（Moodboard） | 品牌定位章节中以情绪关键词 + 意象图片网格表达定位方向的版面 |
| 素材池 | 项目内经过整理（分类、去重、质检）的竞品图片集合 |
| 竞品清单 | 纳入分析的竞品型号列表（品牌、型号、素材可用性） |
| 页面规划策略 | 应用给出的整体页面安排：竞品数量、每车页数、章节构成、页序 |
| 页面模型（Page IR） | 每一页的结构化 JSON 描述（版式、槽位、素材、文案、样式、来源），是页面的唯一事实源；PPTX/PDF 是其渲染产物 |
| 母版 | 报告的版式模板，由团队自行设计，提供多套供用户选择 |
| 检查点 | 流程中必须人工确认方可继续的环节 |

## 3. 用户画像与典型场景

**用户画像**：工业设计师，熟练使用 PowerPoint/WPS 与 3D/平面设计软件，每周启动 1–2 个前期分析任务，习惯在报告初稿上反复修改后再汇报。

**典型场景**：某工程机械企业启动新一轮外观部件迭代，需要向客户（国企）汇报前期分析以对齐设计风格与边界。设计师在工具中创建项目 → 导入甲方提供的零散竞品图片并自动整理 → 确认竞品清单与页面规划 → 系统逐车生成分析页 → 设计师逐页审阅并用自然语言指令修改 → 导出可编辑 PPTX，在 Office 中做最后的微调后交付汇报。

---

## 4. 核心业务流程

```
① 创建项目：设备类型 / 目标客户 / 关注部件范围
② 素材导入：上传零散竞品图片 → 自动整理为竞品素材池（FR-1）
   （P1.5 起支持联网竞品检索补充素材与资料）
③ 规划确认【检查点一】：应用给出竞品清单 + 页面规划策略
   （每车页数、章节构成、品牌家族页序）→ 用户增删与调整
④ 报告制作：逐车图像分析（FR-2）→ 内容生成 → 页面渲染（FR-5）
⑤ 审阅迭代【检查点二，循环】：页面缩略图选择 + 自然语言修改指令
   → 基于页面模型定向修改 → 重渲染预览（FR-6）
⑥ 输出：导出可编辑 PPTX + PDF 预览
```

流程原则：**检查点强制人工确认**；所有生成内容可溯源（图片文件名 / 检索来源）；用户可随时导出已确认的部分。

## 5. 功能需求

### 5.0 模块总览

| 模块 | 名称 | 概述 | 优先级 |
|---|---|---|---|
| FR-1 | 素材检索与整理 | 散图自动整理（P0）；联网竞品检索（P1）；素材池管理（P1） | P0/P1 |
| FR-2 | 图像分析引擎 | 视图分类、色彩分析、部件标注、风格关键词 | P0 |
| FR-3 | 特征线条提取 | 独立技术验证专项，单独实验 | 专项（P1） |
| FR-4 | 报告规划 | 竞品清单与页面规划策略生成、人工确认 | P0 |
| FR-5 | 报告生成与渲染 | 页面模型、模板渲染、PPTX/PDF 导出 | P0 |
| FR-6 | 交互式编辑 | 页面选择 + 自然语言修改，基于页面模型 | P0（基础） |
| FR-7 | 项目与素材库管理 | 项目列表、素材复用、导出历史 | P1 |
| FR-8 | 模板管理 | 多母版选择 | P1（MVP 内置一套） |

### FR-1 素材检索与整理

> 定位：本产品的重点模块。用户与甲方提供的图片特征为**无分类、背景杂乱（展会 / 现场拍摄）、质量参差**；人工检索与整理素材是最耗时的环节，本模块即为解决该环节而设。架构上作为**独立 Agent** 设计（可独立演示与复用），对外提供清晰的服务接口。

**FR-1.1 散图自动整理（P0）**
- 批量上传零散图片后自动完成：品牌 / 型号识别（基于可见 Logo、铭牌、外观特征）、视图类型分类（正面 3/4、正侧、尾部、局部特写等）、质量评估（分辨率、模糊、过曝、遮挡、背景杂乱度）、相同设备多角度聚类；
- 输出结构化竞品素材池，每张图片带标签与质量分，支持用户逐张确认与人工改标；
- 无法识别型号的图片归入"待确认"分组，不强行猜测。

**FR-1.2 联网竞品检索（P1，MVP 后第一优先）**
- 输入设备类型 / 品牌范围，检索竞品型号清单、基本资料与图片；
- 对检索结果执行与 FR-1.1 相同的质量筛选与归类，并入素材池；
- 记录来源 URL，保证可溯源；来源与合规边界见开放问题 #2。

**FR-1.3 素材池管理（P1）**
- 素材池浏览、筛选、改标、重命名；项目间素材复用（依赖 FR-7）。

**验收要点（暂定值，以评测集校准后修订）**：有可见 Logo/铭牌时品牌识别准确率 ≥ 90%；视图分类准确率 ≥ 85%；模糊 / 严重遮挡图片自动标记率 ≥ 90%；同设备聚类准确率 ≥ 80%。

### FR-2 图像分析引擎

对素材池中每台竞品设备执行结构化分析，输出进入页面模型：

- **FR-2.1 视图分类与主图选择（P0）**：为每台设备选出正面 3/4 主图、侧面图等关键视图；
- **FR-2.2 色彩比例分析（P0）**：提取车身主体区域主色 2–4 色及占比，生成色彩比例条数据；
- **FR-2.3 部件标注（P0）**：按附录 B 部件词表逐类输出：部件特写裁图 + 类别标签 + 1–3 行专业描述（形态 / 材质 / 工艺 / 姿态）；词表支持扩展与项目级自定义；
- **FR-2.4 风格关键词（P0）**：生成三词风格关键词组。

**验收要点（暂定）**：主色与人工取样一致率 ≥ 90%、占比误差 ≤ 10%；部件类别命中 ≥ 85%；裁图可用率（准确框住目标部件）≥ 90%；描述设计师评分 ≥ 4/5；风格关键词采纳率 ≥ 60%。

### FR-3 特征线条提取（技术验证专项）

- 独立模块、独立实验推进，**不预设降级方案**；目标为：原图 → 去饱和底图 + 品牌色矢量特征线叠加；
- 技术路线（候选：边缘检测 / 分割辅助 / VLM 引导矢量描线 / 生成式方案）经多轮实验与设计师评审后确定；
- 在达标前，单车页版式**预留线条图槽**，支持人工放置线稿；达标标准与技术结论以实验报告形式归档 `docs/`。

### FR-4 报告规划（P0）

- 基于素材池生成竞品清单（品牌、型号、素材可用性）与**页面规划策略**：竞品数量与取舍建议、每车页数（1/2 页）、章节构成、按品牌家族的页序；
- 以可视化方式呈现【检查点一】，支持用户增删竞品、调整页数与顺序后锁定规划。

**验收要点**：规划策略在素材池变化时可增量重算；用户调整后生成过程严格遵循锁定后的规划。

### FR-5 报告生成与渲染（P0）

- **FR-5.1 页面模型（Page IR，P0）**：每页生成为结构化 JSON（版式类型、槽位、图片对象、文案、样式、来源引用），作为页面唯一事实源；PPTX / PDF 均由其确定性渲染而来；
- **FR-5.2 模板渲染引擎（P0）**：Page IR → 可编辑 PPTX（python-pptx 路线）；支持品牌主题（页眉下划线色、Logo、字体随品牌 / 客户变化）；
- **FR-5.3 封面与目录（P0，简版）**：自动生成封面（客户 Logo、标题、主视觉）与目录（按品牌家族分组、页码正确）；
- **FR-5.4 章节类型扩展（P1/P2）**：局部设计分析、品牌设计分析、品牌定位情绪版（见路线图）。

**验收要点**：导出 PPTX 中文本、图片、形状均为原生可编辑对象（Office 与 WPS 双验证），禁止整页贴图；版式与母版设计稿关键元素位置一致；目录页码与实际页序一致。

### FR-6 交互式编辑（P0 基础 / P1 增强）

- 交互范式：页面缩略图列表 → 选中页面 → 自然语言修改指令 → 应用基于**页面模型**做结构化修改 → 重渲染预览。AI 通过页面模型即知页面结构，**无需以视觉方式重读页面**；视觉仅用于可选的成稿质检；
- 基础指令类型（P0）：修改文案、替换图片（从素材池选）、增删部件标注、修改风格关键词、整页重写；
- 增强能力（P1）：文本框直接编辑、拖拽换图、批量指令、跨页指令（如"所有页把'厚重'改为'敦实'"）、修改历史与撤销。

**验收要点**：指令定位到正确页面的准确率 ≥ 95%；基础指令类型全覆盖；单页修改后重渲染 ≤ 30 秒（暂定）；支持撤销上一次修改。

### FR-7 项目与素材库管理（P1）

项目列表与状态、导出历史版本留存、素材跨项目复用。

### FR-8 模板管理（P1）

- 母版由团队自行设计，提供**多套**供用户按项目 / 客户选择；
- MVP 内置一套母版跑通链路；母版设计规范与源文件管理方式见开放问题 #4。

## 6. 非功能需求

| NFR-8 | 评测 | 对 FR-1 散图整理、FR-2 图像分析、FR-5 内容质量建立评测集与指标；任何 Prompt / 模型 / 流程变更须通过评测方可合入 |

## 7. MVP 范围

### 7.1 MVP 包含（In）

1. 项目创建（设备类型 / 目标客户 / 关注部件范围）；
2. 散图上传与自动整理（FR-1.1）；
3. 竞品清单与页面规划确认（FR-4，检查点一）；
4. 单车分析页自动生成：色彩比例条 + 部件标注 + 风格关键词 + 页眉页脚（FR-2 + FR-5）；
5. 封面与目录（简版，FR-5.3）；
6. 页面选择 + 自然语言编辑（FR-6 基础，检查点二循环）；
7. 导出可编辑 PPTX 与 PDF 预览；
8. 基础成本计量与调用观测（NFR-2 / NFR-5 简版）。

### 7.2 MVP 明确不包含（Out，列入后续版本）

| 内容 | 后续安排 |
|---|---|
| 联网竞品检索（FR-1.2） | MVP 后第一优先（P1.5） |
| 特征线条自动提取（FR-3） | 独立专项并行实验；版式预留图槽支持人工放置线稿 |
| 局部设计分析、品牌设计分析、品牌定位情绪版章节 | P2 |
| 多母版选择（FR-8） | P1，MVP 内置一套 |
| 素材跨项目复用、多人协作、账号体系 | P1 / P3；MVP 为单用户使用 |

## 附录 A：报告页面类型参考

依据真实样例报告《早期卡车分析》（21 页）解剖：

| 页型 | 样例占比 | 内容构成 |
|---|---|---|
| 封面 | 1 页 | 客户 Logo、报告标题（中英双语）、主视觉大图 |
| 竞品分析·单车页 | 13 页 | 页眉（标题 + 品牌色下划线 + 风格关键词）、色彩比例条、特征线条提取、部件标注网格、页脚（型号 + 品牌 Logo） |
| 局部设计分析 | 2 页 | 指定部件跨设备对比：设备图 + 分部件结构化文字卡 |
| 品牌设计分析 | 2 页 | 客户品牌产品图矩阵 + 风格描述段落 + 关键词标签组 |
| 品牌定位（情绪版） | 1 页 | 色彩比例条 + 情绪关键词意象图网格（信赖 / 力量 / 专业 / 可靠等） |

版式关键规律：页眉下划线与叠加线条颜色**跟随品牌主色**；单车页部件类别高度固定（见附录 B）；竞品分析按**品牌家族**排序。
