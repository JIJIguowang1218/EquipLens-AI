# 专门工程车来源调研（初筛）

## 候选来源

### 中文行业媒体/图集

- 卡车之家：`360che.com`，车型图片/公告/实拍较多，适合卡车类。
- 中国卡车网：`chinatruck.org`，行业新闻/车型页。
- 第一商用车网：`cvworld.cn`，商用车新闻/图集。
- 中国路面机械网：`lmjx.net`，工程机械品牌图集（如徐工、山河智能）。
- 铁臂商城/21-sun：`photo.21-sun.com`，工程机械产品图/参数。

### 官方/公告

- 各 OEM 官网产品页/图集；
- 工信部公告/车型公示（适合身份核验，不一定有高清图）；
- 出口商/海外经销商图集（KAMAZ 等）。

### 海外二手/设备目录

- MachineryTrader、TruckPaper（Sandhills）：设备照片多，但以二手销售为主，标题/配置需核验。

## 建议

不要“全网再挖一层”；做**来源注册表 + 分层**：

1. 官方/公告：身份优先；
2. 行业媒体/图集：图片优先；
3. 二手/出口：补充稀有型号，但需更强核验；
4. B2B/商品页：低优先，噪声大。

先选 1–2 个来源做单变量测试，不一次接很多。
