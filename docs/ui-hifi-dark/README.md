## v3 改了什么（2026-11-07，当前）

针对评审反馈的五点：

1. **未选车不再半透明**：图片不透明度恒为 1，改用「亮度/饱和压暗 + 同色遮罩」；未选与备选仍是完整的一块暗牌，不会和页面底糊在一起。
2. **面板头左侧加单色图标**：关联分析（三节点）/ 清单（列表）/ 部件分析（扫描框）/ 页面（双层纸页），12px、1.25px 描边、`--ink-3`；同时删掉 `关联分析` 的 3px 绿条。
3. **右栏条目改成卡片结构**：清单 =「序号槽 ┃ 头行（名称 + 层级记账）┃ 元字段 ┃ 发丝线 ┃ 原因两行」；部件卡 =「头行（序号/名称/构型名/状态）+ 形制 + CMF/族 两列字段框 + 意图行」。
4. **关联度改成单色阶梯**：精确 = 激光绿 `#C7F14F`，环境 `#AFD463`、平台 `#93AE5E` 沿同色相降档，跨类退成中性灰 `#848D99`；位置从左缘色条移到**头行右端**，记号 5/4/3px 递减，跨类虚线空心。
5. **S2 图片贴边**：原图改 `object-fit:contain` 铺满画布，任何尺寸都有一边顶边；框层按 contain 的内容矩形定位（扣 1px 边框）。
6. **加载指示**：状态词前 12px 单色旋转环（进行中），完成后换静态 ◉；只有黑白，不用强调色。

### v3.1 修了什么（2026-11-07 第二轮评审）

7. **面板头图标位置修好**：图标 `<span class="ph">` 之前被 `.hd span`（计数 chip 的样式）误伤，变成靠右的黑框；改为 `.cnt` 专用类后，图标回到标题左侧。
8. **右栏整体放大**：序号 11px、名称 13.5px、标签 10px、元字段 10.5px、原因 11px；部件卡形制 11.5px、字段 11px；卡片间距与描边一起加强，分界更清楚。
9. **关联度发光**：记号与标签各带该档颜色的辉光（`box-shadow` 三层 + `text-shadow`），跨类灰档最弱。
10. **S1 卡片点击展开证据**：点卡片向下放大出证据（标题 + 来源 + 置信度），再点收回，点别的换开；勾选与切图不展开。
11. **关联度只在右栏发光，而且是「漏光」**（v3.2 → v3.3 定稿）：光来自卡片背后一块模糊的同色光斑（`::after` + `blur(12px)`），配三层负扩散柔光；卡边仍是近乎中性的发丝线，不做粗描边。四档靠强度递减：精确 44% → 环境 34% → 平台 26% → 跨类 16%。
12. **主图区不发光**：车辆卡回到中性表面（`border:var(--line)` + 常规阴影），发光只属于右栏那列数据。
13. **S2 五张部件卡全部常开、同高 196px**：本图看不到的部件用同高占位块说明，不编造字段；点击只做选中——对应部件框在照片上发光，点框也能反向选中卡片。

## v2 做了什么（历史，配色已被 v3 取代）

- **换掉琥珀**：主强调色改为激光绿 `#C7F14F`，只给主行动、选中勾、当前刻度。
- **关联度四色索引**（v3 已删除）：精确绿 `#5FD69F`、环境青 `#5AC6E6`、平台橙 `#E7A15F`、跨类玫瑰 `#DE7C87`。
- **卡片重做**：名称、`构型 │ 品牌` 两字段、关联度记号；选中 = 图片复原 + 表面抬起 + 激光绿勾。
- **清单改成独立记录条目**：去掉横线切分（v3 换成序号槽卡片）。
- **面板头部重做**：“关联分析 / 清单 / 部件分析 / 页面”从 9px eyebrow 改为 15px/600 标题 + 计数 chip。
- **S2 规格卡重做**：形制 + CMF/族两列字段框（v3 状态条改为 4px 方点）。
- **字体**：Equip Sans / Equip Sans SC / Equip Mono（基于 IBM Plex，SIL OFL 1.1，子集化并改名）。中文不再依赖系统字体。
- **S3 纸页**：暗色工作台里保留暖白报告纸，作为唯一的浅色锚点。

没有新增任何文案、按钮或功能区；没有移动 8/4 栅格、dock、状态条和控件行。
唯一的代码行为修复是 S2 点“在 图 2 框选”原本不会切图（改为 `startsWith`）；
S1 另外增加了视觉 spans（判断句、规格分隔、清单 tag 移出 `.rt`），没有增删词句。

## 验证

- 1440×900 / 1366×768 / 1280×800：四页无横向溢出、无控制台报错、0 破图；
- S1 八张卡三行完整可见（卡高 203，最后一张底 758 < 内容区 810），卡片区不滚动；
- 清单 8 条各自成卡，面板内滚动（内容 873 / 可视 456）；
- S2 5 条部件卡全部放得下（715 / 715，不滚动）；
- S2 每辆车图片都有一边顶边；框层与内容矩形偏差 ≤0.02px；
- 未选卡 `opacity: 1`，靠滤镜压暗；备选更暗一档；
- 加载指示：进行中 `spin`，完成静态 ◉；
- dock 中心与主行动中心偏差 **0.0px**；输入框右缘 = dock 右缘；
- 字体实际加载：Equip Sans variable、Equip Sans SC 400/500/600、Equip Mono 400/500；
- 渲染文字：S0/S2/S3 与浅色版一致；S1 只在判断句后多一个 DOM 空白，无词句变化。

## 与浅色版的关系

浅色版的 `docs/ui-hifi/` 不做改动，方便对照。两版共用同一份 `data.js` 与图片路径；
因为目录同层，`../../data-test/...` 不需要改。若要把暗色版替换为主版本，
把本目录的 HTML/CSS/JS/data 覆盖回 `docs/ui-hifi/` 即可。
