# EquipLens · 暗色高保真（Darkroom v2）

> 当前进度、下一步与已知边界见 [../HANDOFF.md](../HANDOFF.md) §0.0。

浅色版保留在 `../ui-hifi/`；这里是**第二版暗色重设计**。结构、文案、按钮位置不变，
重做配色、面板头部、卡片与记录条目。设计依据见 [DESIGN.md](DESIGN.md)，
与低保真/浅色版的逐条核对见 [CONFORMANCE.md](CONFORMANCE.md)。

## 打开

直接开 `index.html`；或从 `s0.html` 开始走完整条流程：

**立项 → 检索 → 素材与分析 → 排版**

每页支持 `?s=loading|ready`。不带参数时 S0 直接 ready，S1–S3 默认走 loading。

| 页 | loading | ready |
|---|---|---|
| S1 检索 | 6 张骨架卡 + 清单占位条 + 进度 1/7 | 8 张卡逐张入场，右侧清单同步长出 |
| S2 素材 | 照片虚化（只糊照片，不糊按钮）+ 部件行骨架 | 框选层、部件规格卡、胶片条 |
| S3 排版 | 纸面加载条 + 页缩略图逐页生成 | 12 页预览，可点块选中 |

## 这一版做了什么

- **换掉琥珀**：主强调色改为激光绿 `#C7F14F`，只给主行动、选中勾、live 点、当前刻度。
- **关联度四色索引**：精确绿 `#5FD69F`、环境青 `#5AC6E6`、平台橙 `#E7A15F`、跨类玫瑰 `#DE7C87`。
  每色只占 3px 左条、5px 点、9–10px 胶囊，绝不整行填色；文字与跨类虚线仍然兜底。
- **卡片重做**：名称、`构型 │ 品牌` 两字段、关联度胶囊；选中 = 图片复原 + 表面抬起 + 激光绿勾；
  未选 = 图片 46% + 名称转灰；备选 = 虚线 + 无勾。
- **清单改成独立记录胶囊**：每条 3px 层级色左缘 + 9.5px 状态胶囊 + 原因；去掉横线切分。
- **面板头部重做**：“关联分析 / 清单 / 部件分析 / 页面”从 9px eyebrow 改为 15px/600 标题 + 计数 chip；
  分析正文先读一句判断句，再读展开段。
- **S2 规格卡重做**：3px 状态条 + 状态 chip + 形制 + CMF/族两列字段框 + 意图行。
- **字体**：Equip Sans / Equip Sans SC / Equip Mono（基于 IBM Plex，SIL OFL 1.1，子集化并改名）。
  中文不再依赖系统字体。
- **S3 纸页**：暗色工作台里保留暖白报告纸，作为唯一的浅色锚点。

没有新增任何文案、按钮或功能区；没有移动 8/4 栅格、dock、状态条和控件行。
唯一的代码行为修复是 S2 点“在 图 2 框选”原本不会切图（改为 `startsWith`）；
S1 另外增加了视觉 spans（判断句、规格分隔、清单 tag 移出 `.rt`），没有增删词句。

## 设计审查

本版安装并应用了 [Unparalleled UI](https://github.com/Phantom-Con-Artist/unparalleled-skillset)（MIT），

[DESIGN.md §1](DESIGN.md)。

## 验证

- 1440×900：四页无横向溢出、无控制台报错、0 破图；
- S1 八张卡三行完整可见（卡高 213，最后一张底 789 < 内容区 810）；
- 清单 8 条各自成卡，面板内滚动；
- S2 5 条部件行全部放得下；
- dock 中心与主行动中心偏差 **0.0px**；输入框右缘 = dock 右缘；
- 字体实际加载：Equip Sans variable、Equip Sans SC 400/500/600、Equip Mono 400/500；
- 渲染文字：S0/S2/S3 与浅色版一致；S1 只在判断句后多一个 DOM 空白，无词句变化。

## 与浅色版的关系

浅色版的 `docs/ui-hifi/` 不做改动，方便对照。两版共用同一份 `data.js` 与图片路径；
因为目录同层，`../../data-test/...` 不需要改。若要把暗色版替换为主版本，
把本目录的 HTML/CSS/JS/data 覆盖回 `docs/ui-hifi/` 即可。
