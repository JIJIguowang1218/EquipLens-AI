## 4. 代码改动

### 4.1 行为修复（S2）

`s2.html`：

```diff
- if (st === 'elsewhere') {
+ if (st.startsWith('elsewhere')) {
```

`stateOf()` 返回 `elsewhere:1`，原判断永远不成立，点“在 图 2 框选”不会切图。
改为 `startsWith` 后行为与 v3 §4.3 一致。这是旧版已有 bug，不是本轮视觉改动引入的。

### 4.2 S1 视觉层（不增减文字）

- 判断句：`#prose` 的第一句包进 `<strong class="lead">`，作为结论先读；其余仍是同一段文字。
- 规格：`c.label` 在 ` · ` 处拆成 `构型` / `品牌` 两个 span；`·` 仍在 DOM 中（`&nbsp;·&nbsp;`），
  视觉上被 1px 竖线替换。
- 清单：`.tag` 从 `.rt` 移出，成为 `.rrow` 的直接 grid 子项，才能对齐到右上（原来 grid-area 是无效的）。
- 模型名去掉 `mono` class，用界面字体；类别/计数仍用等宽。

这些都是卡片/清单内部设计，不改变功能、按钮位置和词句。

## 5. 视觉层的纯 CSS 修正

1. S1 检索中：`#prose` 在骨架存在时用 `:has()` 隐藏，避免散文和骨架叠在一起；
2. S2 分析中：旧代码把 `filter: blur(6px)` 加在整个 `.viewer` 上，连左右按钮一起糊。
   现在用属性选择器把父级 filter 取消，只糊 `.fg`；
3. S1 清单为空时，用 `:empty::before` 显示占位条；有数据后自动消失；
4. live 点去掉脉冲；状态条底部进度线只在 `.live` 时用激光绿，其它时候是中灰。

## 11. v3.2 增量（2026-11-07）——关联度改为「卡片边缘发光」

反馈原话：“关联度发光要的是条目卡边缘发光，要的就是显眼一点，现在这样根本看不出区别。”

上一版把发光做在**记号旁边**（`box-shadow` 10/20px、alpha 65/85%），面积太小、衰减太快；像素取样显示标签外 3px 的 d 只有 ~40，和背景几乎无差。v3.2 改为**发光挂在卡片本体边缘**。

| 项 | v3.1 | v3.2 |
|---|---|---|
| 发光位置 | 记号 + 标签文字 | 卡片边框 + 外扩光晕 + 内侧微光 |
| 边框 | 灰白 11% | 该档色，alpha 96/84/70/52% |
| 近场环 | 无 | `0 0 0 2px` 该档色 82/64/48/32% |
| 外扩光晕 | 10/20px | 30px spread 2px，同档 alpha |
| 内侧微光 | 无 | `inset 0 0 26px -10px` 44/33/26/16% |
| 备选卡 | 18% 固定 | `calc(--tg * .55)`，弱但仍在 |
| 滚动容器 | `padding:1px`，把外侧光晕裁平 | `padding:10px 10px 8px`，光晕有空间 |

## 12. v3.3 增量（2026-11-07）——发光收回到右栏、改成漏光；S2 全部常开

反馈原文：“主图区域不需要发光，我说的一直都是右栏……太显眼太生硬，要那种光从卡片边缘漏出来的感觉而不是先描一个粗边再做发光。S2 的卡片点击展开逻辑有问题，应该全部直接做成展开，只是点到哪个部件哪个框和 S1 右栏那样发光即可。”

| 项 | v3.2 | v3.3 |
|---|---|---|
| 主图车辆卡 | 边缘发光 | **完全不发光**（`border:1px var(--line)` + `--sh-1`，与 v3 一致） |
| 右栏卡边 | 1px 档位色 96/84/70/52% + `0 0 0 2px` 实心环 | 1px 近乎中性（档位色 15%）+ **无 0 扩散环** |
| 右栏发光方式 | 描边 + 光晕（边线 d=285 的亮线） | **背后光斑**（`::after` inset -5、17%、blur 12、z -1）+ 三层负扩散柔光 |
| 衰减 | 边线 285 → 2px 259 → 4px 98（台阶明显） | 边线 82 → 1px 74 → 3px 54 → 6px 34 → 10px 21 → 16px 12（单调平滑） |
| S2 部件卡 | 有数据的展开、无数据的压成 67px 一行 | **五张全部常开、匀高 196px**；无数据的给同高占位块（不编造字段） |
| S2 点击 | 选中 + 切图 | 选中 + 切图 + **该部件框发光**（`.bx.on` 14/34px 双层柔光）+ 卡片漏光；点框反向选中卡片 |

### 12.1 实测

- 右栏三档衰减曲线（d）：精确 82/74/54/34/21/12，环境 78/52/38/24/15/12，平台 71/35/24/15/10/12。
- 主图卡片外侧：d≈10~15，等于背景 → 确认无光。
- S2 五卡高度 196/196/196/196/196，`data-tier` 一致；点卡与点框双向同步（`onRows=1`、`onBoxes=1`）。
- 三档视口：无横向溢出、零报错、零破图；S1 八卡仍三行放下（233×202，最后一张底 758 < 810）。
