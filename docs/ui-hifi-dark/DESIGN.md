---

## 0. 一句话

**暗房**：照片是唯一的高亮面，UI 退成石墨与发丝线。**激光绿**只回答“现在轮到你 / 系统正在动”；关联度是**单一色相的阶梯 + 几何记号**（精确最亮、最低档退成中性灰），每条记录有独立区域与文字记账；报告页保留一张被灯照亮的纸。

这一版不是“把浅色反相”，也不是“把琥珀换成绿色”。核心变化是：**结构化的内容不再当普通段落排版，而是按功能拆成头部、字段、状态和记录单元。**

## 1. 设计审查：Unparalleled UI 指出了什么

安装位置：`~/.dsh/skills/unparalleled-ui`（来源 [Phantom-Con-Artist/unparalleled-skillset](https://github.com/Phantom-Con-Artist/unparalleled-skillset)，MIT）。它专门审“dashboard / data table / editor / 复杂工作流”的界面，并明确把以下几类当成问题：

| 审查发现 | 本版处理 |
|---|---|
| 用横线切分列表行，行与行没有独立区域 | S1 清单改为**独立记录卡**：序号槽 ┃ 头行 ┃ 元字段 ┃ 原因，序号与内容之间用竖线做结构分隔，行与行之间不再画 `border-bottom` |
| “关联分析 / 清单 / 部件分析”是 9px 的 eyebrow，重要信息被当普通文本 | 全部改为**面板头**：15px/600 标题 + 计数 chip + 独立头部表面 + 底发丝线；v3 起标题左侧加 **12px 单色线性图标**，删掉原来的 3px 绿条 |
| 关联度只有文字标签，颜色没有承担索引 | v3 改为**单色阶梯 + 几何记号**：精确=激光绿，环境/平台沿同色相降档，跨类=中性灰；记号按 5/4/3px 递减，跨类虚线空心；颜色只做第二信号 |
| 卡片文字区只是“名称 / 副标题 / 标签”三行流 | 卡片是**数据牌**：名称 + `构型 │ 品牌` 两字段 + 关联度记号行；图片与文字之间加发丝线 |
| 卡片选中只靠勾选框，不够明显 | **未选压暗而不是透明**：图片保持不透明，用亮度/饱和「关灯」+ 同色遮罩；选中=图片复原、表面抬起、激光绿实心勾；不做彩色整圈 |
| 状态点脉冲、小标签闪烁 | 状态改为**单色旋转环（进行中）/ 静态 ◉（完成）**，不再 pulse；进度由真实计数驱动 |
| 一处颜色用在所有地方 | 激光绿只给主行动 / 选中 / 待框选 / 精确类目；其余层级走同色相降档与明度，不再有第二套分类色 |
| S2 的 CMF / 族 / 意图全挤成一行 | CMF / 族是**两列字段框**（标签在上、值在下）；意图单独成行；状态是 4px 方点 + 文字 |

> v2 曾按“条目内要有颜色区分”引入四个分类色（青/橙/玫瑰）；v3 评审结论是这套色与石墨底不搭，改为**同色相阶梯 + 几何记号**：只有一个色相（激光绿系），最低档退成中性灰。主强调色仍只有一个。

### 卡片参考（开源项目）

- **[shadcn/ui Card](https://ui.shadcn.com/docs/components/card)**：卡片不是“一个白盒子”，而是 header / content / footer 的功能分区。本版把卡片拆成图片区、数据牌、状态胶囊。
- **[Cal.com](https://github.com/calcom/cal.com) 的 event type 卡**：封面/标题/元信息/状态并置，状态用小型 chip 而不是一整行彩色。本版借用“图片 + 标题 + 规格 + 状态”的纵向节奏。
- **[Vercel Commerce](https://github.com/vercel/commerce) 的 product card**：图片是主角，名称/规格/价格保持对齐；卡片内部靠字号与间距分层，不靠彩色底。本版借用“图片优先、元信息紧凑、状态独立”的结构。

## 2. 色板

### 2.1 中性色（结构）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0A0B0D` | 页面底；近黑不纯黑 |
| `--surface` | `#121418` | 卡片、面板 |
| `--surface-2` | `#161A1F` | 卡片悬停 |
| `--surface-3` | `#1C2027` | 浮层、toast |
| `--line` | `rgba(232,238,246,.07)` | 发丝线、卡片边 |
| `--line-2` | `rgba(232,238,246,.13)` | 可交互控件边、字段分隔 |
| `--ink` | `#ECEFF3` | 标题、当前态 |
| `--ink-2` | `#A9B1BB` | 正文、次级信息 |
| `--ink-3` | `#7C8591` | 元信息、说明 |
| `--ink-4` | `#5C646F` | 占位、极弱标签 |

### 2.2 主强调色：激光绿

| 令牌 | 值 | 用途 |
|---|---|---|
| `--accent` | `#C7F14F` | 当前阶段刻度、主按钮、选中勾、待框选方点、精确类目记账 |
| `--accent-hi` | `#D8FB66` | 主按钮悬停 |
| `--accent-ink` | `#101405` | 激光绿底上的文字（14.34:1） |

激光绿偏黄、较亮，接近工业激光/荧光标记，不是“赛博青”。它只承担“现在/你/已选”这一类语义，不做大面积底色，也不做每条记录的分类色。

### 2.3 关联度：单色阶梯 + 几何记号（v3）

| 轴 | 令牌 | 值 | 记号 | 对 `--surface` 对比度 |
|---|---|---|---|---|
| 精确类目 | `--t-exact` | `#C7F14F` | 5px 实心方点 | 14.16 |
| 环境特化 | `--t-env` | `#AFD463` | 4px 实心方点 | 10.90 |
| 基型平台 | `--t-plat` | `#93AE5E` | 3px 实心方点 | 7.42 |
| 跨车型 | `--t-cross` | `#848D99` | 4px 虚线空心方点 | 5.49 |

最强档就是激光绿本身，中间两档沿同一色相降亮降饱和，最低档退成中性灰——**只有一个色相**，不与石墨底打架。层级同时由记号大小与虚实表达，颜色只是第二信号，文字始终在场。

位置也变了：v2 放在卡片左缘的 3px 色条与彩色胶囊；v3 移到**头行右端**（名称右侧），是「记账」而不是「装饰条」。

### 2.4 流程状态（S2 部件卡）

| 状态 | 颜色 | 形态 |
|---|---|---|
| 已框定 | `--s-framed #A9B1BB` | 4px 方点 + “已框定” |
| 本图可见 · 待框选 | `--s-pending` = 激光绿 | 4px 方点 + 文字；唯一“需要你动手”的状态 |
| 在 图 N 框选 | `--s-elsewhere #7C8591` | 4px 方点 + “在 图 2 框选” |
| 本图不可见 | `--s-hidden #4A515C` | 几乎隐去的方点 + “本图不可见” |

流程状态与关联度无关，但同样只允许石墨 + 激光绿；v2 的钢蓝/青灰已删除。

### 2.5 对比度实测

| 前景 | 背景 | 比值 |
|---|---|---|
| `--ink #ECEFF3` | `--surface #121418` | 15.99 |
| `--ink-2 #A9B1BB` | 同上 | 8.51 |
| `--ink-3 #7C8591` | 同上 | 4.94 |
| `--accent #C7F14F` | `--surface` | 14.16 |
| `--accent-ink #101405` | `--accent` | 14.34 |
| `--t-exact #C7F14F` | `--surface` | 14.16 |
| `--t-env #AFD463` | 同上 | 10.90 |
| `--t-plat #93AE5E` | 同上 | 7.42 |
| `--t-cross #848D99` | 同上 | 5.49 |
| 纸面正文 `#191A1D` | 纸 `#F7F4EC` | 15.83 |
| 纸面弱文 `#5A574F` | 纸 | 6.56 |
| 纸面元信息 `#6B665B` | 纸 | 5.20 |

阶梯四档全部过 4.5:1（最弱的跨类 5.49），9px 的清单记账文字也在 5.4 以上。颜色从不单独承载语义：每档都有**记号形状 + 文字**配合；跨类额外用虚线空心记号。

### 2.6 用色纪律

1. 激光绿只用于“现在/你/已选/待框选/精确类目”：主按钮、选中勾、当前刻度、待框选方点、最强档记账。
2. 关联度是**单色阶梯**，不是四套分类色：只有一个色相，最低档退成中性灰；每档配记号形状与文字。允许**卡片边缘按档位发光**，但绝不整行/整卡填色。
3. 未选态用**压暗**（亮度/饱和 + 同色遮罩）而不是透明度；颜色必须配文字；选中必须同时有勾、图片明度差和表面差。
4. 面板头用 12px 单色线性图标标识，图标不发光、不上色；不要退回 3px 彩色模块条。
5. 加载指示只有黑白：进行中是旋转环，完成后是静态 ◉，不用强调色。
6. 报告纸是唯一的大面积浅色；不要为了“统一”把纸改成暗色。

## 3. 字体

### 3.1 选型

| 角色 | 字体 | 字重 |
|---|---|---|
| 拉丁 / 数字 / 界面 | **Equip Sans**（基于 IBM Plex Sans，variable） | 100–700 |
| 简体中文 / 中文标点 | **Equip Sans SC**（基于 IBM Plex Sans SC 子集） | 400 / 500 / 600 |
| 计数、页码、序号、字段标签 | **Equip Mono**（基于 IBM Plex Mono） | 400 / 500 / 600 |

Plex 的方切、紧凑字幅和工程感贴合设备/测量语境；Plex Sans 与 Plex Sans SC 同属一个设计家族，中英混排不会出现两套骨架。等宽只做数据和标签，不做标题。

### 3.2 商用与许可

- 三套字体均为 **SIL Open Font License 1.1**：允许商用、嵌入、子集化、随产品分发；不允许单独售卖字体本身。
- IBM Plex 带 **Reserved Font Name “Plex”**，所以子集文件已把 family / full / PostScript / named instance 全部改成 **Equip Sans / Equip Sans SC / Equip Mono**，字形轮廓未改。
- 许可原文在 `fonts/OFL-*.txt`；来源、字符数、子集方法在 `fonts/README.md`。
- 这解决了原稿“Inter 没有中文，中文实际落到 Microsoft YaHei / PingFang”的隐性问题：中文字体随包分发，跨平台一致。

### 3.3 此版的排印角色

```

- 标题 15px/600，中文字体，不用 9px 等宽大写 eyebrow。

### 4.2 S1 车辆卡

```
┌──────────────────────────────┐
│  [照片 contain + 模糊垫底]    │
│  1 / 4                 [✓]   │

### 4.5 S3 报告纸

- 暗色工作台 + 纸：纸 `#F7F4EC`、正文 `#191A1D`、元信息 `#6B665B`、封面细线 `#5F6E1E`。
- 页面预览头改为 15px/600 + 页码 chip；页块选中用墨色 1.5px 描边 + 纸色手柄。
- 报告纸是暗色界面的视觉锚点，不要改成暗色。

### 4.6 关联度发光：只给右栏，且是「漏光」（v3.3）

三条约束，都是评审逐轮压出来的：

1. **只有右栏（清单条目卡）发光**。主图区的车辆卡不发光——照片、勾选、亮度差已经在抢注意力，再加一层光会糊成霓虹。
2. **不做“先描粗边再发光”**。卡边保持近乎中性的 1px 发丝线（档位色只占 15%），观感上是一条极细的暗线，而不是一圈亮描边。
3. **光从卡片背后漏出来**。实现是两层：

| 层 | 做法 | 效果 |
|---|---|---|
| 背后的光斑 | `.rrow::after` 绝对定位 `inset:-5px`、档位色 17%、`blur(12px)`、`z-index:-1` | 卡面把光斑挡住，只在边缘与卡片缝隙里透出来 |
| 贴边柔光 | 三层 `box-shadow`，全部负扩散（`-3px / -10px / -28px`） | 没有 0 扩散的实心环，衰减平缓 |

实测衰减（距背景 `#0F1114` 的 d）：边线 82 → 外 1px 74 → 3px 54 → 6px 34 → 10px 21 → 16px 12。边线数值低于紧邻外侧的衰减曲线起点，所以读起来是“光溢出来”，不是“画了一条亮线”。

四档强度：精确 44% → 环境 34% → 平台 26% → 跨类 16%（灰），曲线同形，区别在幅度。

### 4.7 S1 卡片展开证据（v3.1）

- 点卡片正文 → 卡片向下放大，展开证据区；再点同一张收回；点另一张先关旧再开新（手风琴，同时只开一张）。
- 点勾选框只切换入册状态、不展开；点图片只切换图片、不展开。
- 证据区：`证据 E3 · N 条来源` → 每条「标题（两行截断）+ 来源域名」→ 底部 `置信 xx% / 推荐·可入册`。
