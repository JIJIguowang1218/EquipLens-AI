# v4 低保真 · 12 栏

打开 `index.html` 进入四页索引；四页也可单独打开。

## 与 v3 的区别

只改**版式与骨架**，内容、交互、状态机与 v3 相同（页面里保留了同样的 `?s=` 参数与 dock 行为）。

| 项 | v3 | v4 |
|---|---|---|
| 左栏 | `clamp(200,21vw,280)`，无栅格概念 | 同宽，但明确定义为 **rail，不参与 12 栏** |
| 内容区 | flex + `clamp()` 连续内边距 | `grid-template-columns:repeat(12,minmax(0,1fr))`，`--margin` / `--gutter` 令牌 |
| 右栏宽度 | S1 `23vw` / S2 `27vw` / S3 `17vw`（三页各不相同） | 三页统一 **9–12 栏**（1440 下 360px） |
| 分界线 | 1084.8 / 1027.2 / 1186（换页跳 57–159px） | 1056（三页一致，残差 0） |
| 卡片 | 3 列、gap 12 | 3 列、gap = `--gutter` 16，位于 8 栏内（嵌套栅格） |
| 进度条 | 5 段 `flex:1` 等分 | 5 段按 **2/2/3/3/2** 栏分配，段边界压栏线 |
| S0 内容块 | `max-width:720px`（绝对值） | 第 1–8 栏 |
| S3 缩略图 | 单列（190–230px 窄栏） | 4 栏内两列，页名移到缩略图下方 |

## 实测（1440×900）

| 页 | 卡片/画布区 | 右栏 | 栏残差 |
|---|---|---|---|
| S0 | `ask` 304→1040 | — | 0 / 0 |
| S1 | 304→1040（736） | 1056→1416（360） | 0 / 0 |
| S2 | 304→1040（736） | 1056→1416（360） | 0 / 0 |
| S3 | 304→1040（736） | 1056→1416（360） | 0 / 0 |

卡片：234.7 × 3 + 16 × 2 = 736；dock 宽 736（正好 8 栏）。
