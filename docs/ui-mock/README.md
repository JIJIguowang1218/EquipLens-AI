# UI 稿目录（静态稿 + 视觉样张）

## 当前静态稿（v3，可交互，以此为准）

| 文件 | 页面 | 参数 |
|---|---|---|
| `s0.html` | S0 立项台 | — |
| `s1.html` | S1 检索台 | `?s=start` / `?s=mid` / `?s=done`（默认 done） |
| `s2.html` | S2 素材与分析台 | `?s=working` / `?s=done`（默认 done） |
| `s3.html` | S3 排版与导出 | —（页面由右侧预览切换） |

- 直接双击打开；布局流式自适应（窄容器/侧边栏面板也能看全），浏览器 Ctrl ± 可缩放。
- 交互（切车、切图、框选、左右联动、页面切换、导出对话框、底部常驻输入框）都在页面内，纯前端假数据。
- 底部动作坞与顶部阶段名的规则见 `docs/ui-interaction-spec-v3.md` §1.2 / §1.4。

> 交互与状态的权威定义见 **`docs/ui-interaction-spec-v3.md`**。

## 历史视觉样张（v2，仅作视觉参照）

三个 1440×900 画板：`s0`（立项台）、`s1`（检索台 · 结果筛选）、`s1r`（检索台 · 检索中）。

- `screens.html`：单文件样张，纯 CSS，无外部依赖（字体走系统栈）
- `shot.py`：用 Playwright 逐个画板截图（2× 分辨率）

重新生成：

```bash
python docs/ui-mock/shot.py
```

产物：`s0.png` / `s1.png` / `s1r.png`。

> 用途：评审视觉语言（墨/纸、测量轨、裁切标记、等宽型号）是否成立；**不是实现起点**，版面以上面的 v3 静态稿为准。
