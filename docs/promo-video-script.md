# EquipLens 宣传片 · 解说稿 + 字幕稿（v2）

- 时长：**110 秒**（≤2 分钟）
- 类型：解说片
- 结构：问题 → 价值 → 检索 → 关联推荐 → 图筛选 → 结构化 → 交付 → 落版
- 旁白：piper 离线中文 TTS（zh_CN-huayan），可换真人

## 1. 解说稿（逐句）

**[1] 问题 + 价值**（0:00–0:13）
> 一份重卡竞品分析，设计师通常要花两周。
> EquipLens 把这件事压到十分钟：一个类目，换成一份能编辑的分析报告。

**[2] 检索**（0:13–0:33）
> 第一步不是搜图，是搜文字。
> 二十多篇文章里，只有一部分提到具体车型；系统把品牌和型号抽出来，按被提到的次数排序。
> 被反复提到的，才是真正的对手。

**[3] 关联推荐**（0:33–0:57）
> 推荐不是拍脑袋。
> 每台车要回答三个问题：和这个类目什么关系、依据在哪篇文章、那篇文章怎么说的。
> 串起来，就是一条能逐条核对的推理链。
> 所以清单里每一行，都带着来源。

**[4] 图筛选**（0:57–1:14）
> 搜来的图大部分不能用：乘用车、局部特写、和型号对不上。
> 系统给每张图打分，再用类别和型号二次校验，最后按视角排序。
> 十张里通常只留两三张。

**[5] 结构化**（1:14–1:31）
> 留下的图拆成六个部位。
> 每个部位回答四件事：什么构型、属于哪一族、形态怎么描述、材料和颜色是什么。
> 这些不是形容词，是能跨车对比的结构化数据。

**[6] 交付**（1:31–1:45）
> 最后是排版。框不对可以改，字可以改。
> 导出的 PPT 里，每个元素都能编辑。
> 三台车，十页，一份能直接讲的报告。

**[7] 落版**（1:45–1:50）
> EquipLens：把竞品分析，做成十分钟。

## 4. 关于"分段制作"

是**分段制作**，不是一个巨型时间线：

```
promo/
  index.html          # 只放 7 个场景宿主 + 音频
  compositions/
    01-problem.html
    02-retrieval.html
    03-association.html
    04-gate.html
    05-structure.html
    06-delivery.html
    07-endcard.html
```

- 每个场景是独立文件：**改第 3 段，只动 `03-association.html`**，其它场景不受影响
- 可以单独渲染/截图某一段（`hyperframes render --composition compositions/03-...`）先看效果
- 最终整片渲染仍然是把 7 段拼起来跑一遍（几分钟），但**改一句话不用重做整个项目**

## 5. 旁白方案（已实测）

| 方案 | 结果 |
|---|---|
| edge-tts（微软在线音色） | ❌ 403，微软已加 DRM |
| **piper**（本地 ONNX，zh_CN-huayan-medium） | ✅ 已跑通，离线、免费、4 秒出 20 字 |
| Windows SAPI（Huihui） | ✅ 可用，但音色偏旧，作为兜底 |

建议：**piper 生成 + 人工听一遍调语速**（`length_scale` 1.0–1.25）。
