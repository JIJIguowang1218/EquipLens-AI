## A3 英文查询（第二段“英文档”）

**目的**：验证“用英文查询能否提升召回”，并定位对哪些类目/环境有效，且**不引入类目翻译表**
（HOWO/Sitrak/Zetros 这类拉丁名本来就存在，不需要翻译）。

**方法**：同一批 18 个含拉丁名的历史车型，各跑三档图片搜索（只搜不下载）：
- `current` = 现有 `normalize_query`；
- `en_latin` = 拉丁词 + 构型 + `truck`；
- `en_code` = 型号码 + 构型 + `truck`；
统计命中数（过相关性护栏后）与“标题含车型 token”的比例。

**结果**：

| 档位 | 有命中 | 有相关命中 |
|---|---:|---:|
| current | 15/18 | **13/18** |
| en_latin | 13/18 | 11/18 |
| en_code | 11/18 | 6/18 |

分案例看才是关键：

| 场景 | 英文档效果 | 例子 |
|---|---|---|
| **拉丁品牌 + 6×6 卡车（c1 沙漠/油田）** | **明显有帮助** | `HOWO TAZ4922`：0→3 命中；`HOWO TX`：2→6 命中（相关 0→5） |
| 压路机（c5） | 混合 | `SEM518` 3→6（相关 3→6）；`CA260D-II` 退化成 `truck`（拉丁词抽取失败） |
| 正面吊（c2） | **变差** | `RSH4531` 6→1；`RSH4532` 2→0（短码 + truck 召回的是无关卡车） |
| 拖拉机（c3） | 有命中但**不相关** | `YHX2004` 0→4 命中，相关仍 0（噪声） |
| 叉车（c4） | 变差 | `KLA-I` 3→0（`KLA truck` 不是叉车） |

**结论**：**不能默认开启**。英文档只对“有明确拉丁品牌名的卡车类”有效；
对“纯型号码”和“非卡车类目”会引入噪声甚至变差。若要做，只能是**条件档**：
`current` 命中 ≤1 且车型含拉丁品牌词时才试 `品牌 + 构型 + truck`，并保留原护栏。

**冲突**：与“查询档位只保留高质量档”的既有原则一致（可放进 `alias` 之后的新档）；
与 B1 tier 规则配合时，英文档不应算回退档（它不是降级来源），但要用命中率阈值控制。

## C1 同查询标签一致性

**目的**：验证“同一查询 top-k 标题是否共享 token”能否作为图片信度信号。

**方法**：历史 1203 个“同车型 ≥3 张图”的组，计算标题 token 交集是否存在，
对比该组图片的核验通过率。

**结果**：

| 组 | 数量 | 平均核验通过率 |
|---|---:|---:|
| 标题存在共识 token | 560 | **0.90** |
| 无共识 | 643 | 0.65 |

**结论**：**相关，但当前不可作为独立证据**——核验本身就是用标题 token 判身份，
这是**循环论证**；而且标题共识反映的是“同一批搜索结果的写法一致”，
不等于“图里的车对”。要验证它，必须有人工图片标注（谁真、谁错）。
**暂不做**，除非有图片级标注集；否则容易把“系统性错误”当成高信度。

## D1 rank 相关性：按你的意见重新定义

你的判断是对的：**rank 在拿到图之前工作，看不到车长什么样；而人审的“相关”是看图后的判断。**
所以“用人工相关度标签去评价文本 rank”是不公平、也无意义的——它必然显示 rank 弱，
但这不代表 rank 没用，只代表我们问错了问题。

重新定义（建议）：

1. **文本 rank 只评“文本合理性”**：类目是否正确、品牌/车系/型号码是否有效、
   是否被多条独立查询发现。指标用可自动判定的字段，不靠人看图。
2. **视觉相关性属于“看图之后”的环节**：先拿到图，再用门卫/CLIP/核验结果做
   **image-aware re-rank**（或在交付清单里排序）；这时用人工标注才有意义，
   而且标注的是“这张图像不像这款车”，不是“文本排序对不对”。
3. **参照物问题**：即使看图，“像不像”也需要参考图（用户给的目标车图或人工选定基准），
   否则只能判断“是不是卡车/是不是该品牌”，无法判断“是不是这台车”。

**结论**：D1 原方案（文本 rank vs 人工相关度）**作废**；改为两条：
- D1a：文本 rank 的“合理性指标”（自动，可立即做）；
- D1b：图片级相关性（image-aware re-rank + 参考图，需人工标注，后置）。

**冲突**：这条重新定义会影响 backlog 里 A1/A2/D2 的判断——它们都在“文本/来源层”优化，
不能声称提升“视觉相关性”；只能声称提升“可发现性/可识别性”。
