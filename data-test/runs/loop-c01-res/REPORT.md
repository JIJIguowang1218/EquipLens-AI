# C01 隔离检索 loop · 口径修正后重跑（2026-11-10）

## 0. 这次改了什么

| # | 改动 | 原因 |
|---|---|---|
| 1 | 分辨率标签改名：`overview_candidate/part_candidate` → **`res_standard`（长边≥800）/ `res_high`（≥1200）** | 旧名暗示“概览/部件”，但和“图里有没有部件”无关，误导 |
| 2 | 分辨率**不再参与筛选**：`RuleVerifier` 把低清从 defect 改为 warning；`WebWorld` 不再按 ≥800 丢弃 | 两段式门卫已够用；分辨率只作质量档位，交人审 |
| 3 | loop 验收改为 **每台车 ≥1 张通过核验的图** | 没有部件可见性检测，按 5 个部件验收是假指标 |
| 4 | 全局槽位满时不再报单元缺口 | 单元配额是建议，不是硬性 |

## 2. 结论

1. **loop 能收敛到 12/12**——但这是在“每车 ≥1 张图”的口径下；不代表 12 台都能用于报告排版；
2. **每台车只有 2–6 张图**，平均 4 张，仍然偏少；3 台只有低清；
3. **两段式门卫没有改动**：48 张里 4 张预筛拒、7 张 CLIP 拒（多车队列/客车/内饰），其余过门卫；
4. **仍未解决**：型号/上装身份校验（东风天锦混入“高空作业车”“冷藏车”）、召回（120 条下载失败、经销商页）。
