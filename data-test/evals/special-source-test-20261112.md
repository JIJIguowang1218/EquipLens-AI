# 专门来源初测（360che / lmjx）

## 结果

| 来源 | URL | 结果 |
|---|---|---|
| 卡车之家 360che | `product.360che.com/s0/219_63_Pic.html` | HTTP 200，但返回反爬 JS（`arg1=...`），抽图 0 |
| 中国路面机械网 lmjx | `m1.lmjx.net/photo/d/103655/1` | 连接超时，抽图 0 |

## 解释

- 360che 产品图库不是静态 HTML，简单 `requests` + `harvest_source_page` 抽不到图；
- lmjx 图片域名连接超时；
- 这两家不能按普通文章页 harvest 直接接入。

## 结论

- 专门来源**有精度潜力**，但接入成本高于 360 结果页；
- 需要 API/浏览器渲染/反爬处理，不能只加 URL；
- 下一步如果做，先选 1 家能稳定访问的官方/行业源，做单变量测试；不要同时接多家。
