# A/B 评分细则（预注册，2026-10-31）

对象：Arm A（无 skill，自由格式）vs Arm B（加载 `skills/association/`，过 schema）。
评分人只看到匿名化的清单（arm/案例已打乱），每条判 0 / 0.5 / 1。

## 六个维度（每案例满分 6）

| # | 维度 | 1 分标准 | 0.5 分 | 0 分 |
|---|---|---|---|---|
| D1 | 口径/构型 | 识别类目口语化（吨位/底盘形式）或名录构型不符（6x6 vs 6x4），并落到推荐里 | 提到但未影响清单 | 完全按字面类目名检索 |
| D2 | 结构事实 | 对"结构上不存在"的组合显式排除，且说明是事实（非"相关性弱"） | 排除但未给理由 | 把不该有的拉进清单 |
| D3 | 部件轴 | 每个部件的证据轴判断合理（环境/基型/跨车型），且与"能裁什么"一致 | 部分合理 | 全部按单一轴/按名字套 |
| D4 | 理由可审 | 每条写"能提供什么证据"（可裁部件/叙事），来源可指出 | 半数如此 | 大量"相似/同类/同系列" |
| D5 | 必要确认 | 该问的都问了（低置信档案、口径、薄类目、结构事实） | 问了但不关键 | 一个问题都没有 |
| D6 | 诚实度 | 凑不满如实报缺口；不编型号、不编图库数字 | 有缺口未明说 | 凑数/编造 |

格式项（单独记录，不计入六维）：是否过 schema、槽位是否合法、备选是否占槽。

## 各案例的关键判点（评分时对照）

| 案例 | 关键判点 | 期望 |
|---|---|---|
| C1 沙漠牵引车＋踏步/防护栏/底盘 | ①档案 `component_vocab` 不含这三个部件 → 不能按档案词表生成查询；②名录里 天锦/JH6/J6G 多为 6x4 公路构型 | D1 需把 6x4 降为备选/排除；D3 踏步/防护栏/底盘 环境轴优先 |
| C2 重型吊车＋支腿 | ①`重型吊车` 无档案、且是口语类目（要落吨位+底盘形式）；②名录含 XGC88000（履带吊，无支腿）、BJ5311JSQ（随车吊） | D1 落参数；D2 排除履带吊并说明事实；D5 问吨位门槛 |
| C3 随车吊＋支腿 | 档案 confidence 0.4、LLM 草案未确认；起重为主 vs 载货为主 决定支腿证据 | D5 阻断式确认（口径）；确认前不给推荐位 |
| C4 高空作业车＋臂架 | 无档案（盲测类目）；臂架构型分剪叉/曲臂/直臂，证据轴应先判形式 | D1 判形式；D5 提档案缺失 |
| C5 装载机＋铲斗/动臂 | 有档案；铲斗/动臂是**功能件**，构型逻辑跨品牌可比、与"造型"关联弱 | D3 判为工程构型证据（非造型），并说明可裁视角（侧视） |
| C6 混凝土搅拌车＋罐体/进料斗/卸料槽 | 无档案；罐体/进料斗属**上装功能结构**，跨品牌高度同构 | D3 避免把"同构"当"可借鉴设计"；D6 别凑 | 
| C7 矿用宽体自卸车＋货厢/举升油缸/驾驶室防护 | 无档案；矿用宽体与公路自卸是**不同构型族**，货厢举升方式（前顶/中顶/侧翻）不同 | D1 区分构型族；D2 别拿公路自卸当矿用 |
| C8 压缩式垃圾车＋上装/填装器/尾部装置 | 无档案；市政专用车，设计语料极少，属"薄类目"典型 | D6 应报缺口；D5 应确认是否接受同类市政车参照 |

## 判定方法

- 每个案例两臂配对比较（同案例、同预算）；不做跨案例平均的显著性推断（样本太小）。
- 汇总：六维均分 + 格式项达标率；并统计"硬错误"（把 XGC88000 放进支腿推荐、编造车型、备选占槽、阻断项下给推荐）。
- 预注册结论阈值：B 的六维均分需 ≥ A + 0.5（满分 6）且硬错误 ≤ A 的一半，才算"skill 有效"；否则按"无显著差异"处理，先修 skill 而不是加功能。
